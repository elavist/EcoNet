# ECOnet Architecture v3

Distributed Swarm Robotics System for Urban Environmental Cleanup

Author: Concept Engineering Draft\
Language: Russian\
Document type: Unified architecture specification

------------------------------------------------------------------------

# 1. Введение

ECOnet --- это архитектура распределённой системы ройной робототехники,
предназначенной для автоматизированной очистки городских пространств.

Основная идея системы --- использование большого количества небольших
автономных роботов, которые совместно выполняют задачу сбора мелкого
мусора.

Типичные объекты: - окурки - пластиковые фрагменты - бумага - крышки -
мелкий бытовой мусор

Система рассчитана на масштабирование:

  Масштаб   Количество роботов
  --------- --------------------
  Пилот     50
  Район     300--1000
  Город     3000+

------------------------------------------------------------------------

# 2. Философия системы

ECOnet основан на принципах ройной робототехники.

Ключевые идеи:

1.  Децентрализация\
2.  Масштабируемость\
3.  Отказоустойчивость\
4.  Локальные решения\
5.  Простота роботов

Каждый робот выполняет ограниченный набор задач, но совместно рой
демонстрирует сложное поведение.

------------------------------------------------------------------------

# 3. Архитектура системы

Архитектура ECOnet состоит из трёх уровней:

## Уровень робота

-   сенсоры
-   манипулятор
-   мобильная база
-   локальная навигация
-   локальное принятие решений

## Уровень роя

-   распределение задач
-   обмен сообщениями
-   коллективное картографирование

## Уровень инфраструктуры

-   базовые станции
-   зарядные станции
-   облачная аналитика

# 4. Физическая платформа робота

Целевые параметры:

  Параметр   Значение
  ---------- -----------
  Длина      25--35 см
  Ширина     20--25 см
  Высота     15--20 см
  Масса      3--5 кг

Подсистемы:

-   мобильная база
-   манипулятор
-   сенсорный модуль
-   вычислительная система
-   система связи
-   батарея
-   контейнер мусора

------------------------------------------------------------------------

# 5. Мобильная база

Рекомендуемая схема: дифференциальный привод на 4 колёсах.

Преимущества:

-   высокая устойчивость
-   простота управления
-   хорошая проходимость

Параметры двигателей:

  Параметр             Значение
  -------------------- ----------
  Напряжение           12--24 V
  Передаточное число   50--100
  Скорость             до 1 м/с

------------------------------------------------------------------------

# 6. Манипулятор

Манипулятор используется для подбора мусора.

Степени свободы:

1.  вращение базы\
2.  плечо\
3.  локоть\
4.  кисть

Захват: двухпальцевый.

Параметры:

  Параметр       Значение
  -------------- ----------
  Сила захвата   1--2 кг
  Ширина         4--6 см

------------------------------------------------------------------------

# 7. Сенсорная система

Основные сенсоры:

### Камеры

Используются для обнаружения мусора.

  Параметр     Значение
  ------------ ----------
  Разрешение   1080p
  FPS          30--60

### LiDAR

Используется для навигации.

Рекомендуемые модели:

-   RPLidar A1
-   RPLidar A2

### IMU

Используется для ориентации.

Чипы:

-   BNO085
-   MPU9250

### Ультразвуковые сенсоры

Используются для предотвращения столкновений.

------------------------------------------------------------------------

# 8. Вычислительная архитектура

Используется двухуровневая система.

## Контроллер реального времени

Микроконтроллер:

STM32 или ESP32

Задачи:

-   управление моторами
-   считывание энкодеров
-   управление сервоприводами

Частота цикла:

200--500 Гц

## Высокоуровневый компьютер

Варианты:

-   Raspberry Pi 5
-   Jetson Orin Nano

Используется для:

-   компьютерного зрения
-   навигации
-   ройной логики

------------------------------------------------------------------------

# 9. Сетевая коммуникация

Основная сеть:

WiFi Mesh (802.11s)

Альтернативная:

LoRa резервная сеть.

Типы сообщений:

-   состояние робота
-   задачи
-   карта среды
-   предупреждения

Размер пакета:

\<200 байт.

Частота передачи:

2--5 Гц.

------------------------------------------------------------------------

# 10. Координация роя

Алгоритмы:

1.  локальное исследование среды
2.  распределение задач
3.  регулирование плотности роботов

Каждый робот использует локальные данные и сообщения соседей.

------------------------------------------------------------------------

# 11. Алгоритм распределения задач

При обнаружении мусора робот создаёт токен задачи.

Структура токена:

-   координаты
-   тип мусора
-   время
-   ID робота

Роботы поблизости вычисляют ETA и выбирается робот с минимальным
временем прибытия.
