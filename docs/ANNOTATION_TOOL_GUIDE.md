# ✅ Инструмент Ручной Разметки (Annotation Tool)

## 🎯 Реализованный Функционал

### 1. ✅ Инструмент Разметки (`AnnotationTool`)

**Файл:** `obelisk/services/annotation_tool.py`

**Методы:**
- `save_annotation()` - сохранение аннотации с боксами в формате YOLO
- `add_label()` - быстрое добавление метки к изображению

**Функции:**
- Сохранение оригинала изображения
- Сохранение аннотаций в формате YOLO (.txt)
- Сохранение размеченного изображения с боксами
- Автоматическое копирование в папку датасета для обучения

### 2. ✅ Виджет Разметки (`AnnotationWidget`)

**Файл:** `obelisk/ui/annotation_widget.py`

**Функции:**
- Рисование боксов мышью (drag & drop)
- Отображение всех добавленных боксов
- Удаление боксов
- Отмена последнего действия
- Сохранение с confidence 100%

**Управление:**
- **➕ Добавить бокс** - начать рисование
- **↩️ Отменить** - удалить последний бокс
- **🗑️ Очистить** - очистить все боксы
- **💾 Сохранить** - сохранить аннотацию

### 3. ✅ Интеграция в GUI

**Файл:** `obelisk/ui/gui_material.py`

**Добавлено:**
- Кнопка "🎨 Разметка" в панели "Выбор модели"
- Метод `show_annotation_tool()` - открытие инструмента разметки

## 📊 Формат Сохранения

### Изображения:
- **Оригинал:** `datasets/cigarette_butt/train/images/{name}_{timestamp}.jpg`
- **С боксами:** `datasets/cigarette_butt/train/images/{name}_{timestamp}_annotated.jpg`

### Аннотации (YOLO формат):
- **Файл:** `datasets/cigarette_butt/train/labels/{name}_{timestamp}.txt`
- **Формат:** `class_id x_center y_center width height` (нормализованные координаты)
- **Пример:** `0 0.5 0.5 0.2 0.3`

## 🎨 Использование

### Шаг 1: Открыть инструмент разметки
1. Загрузить видео или подключить камеру
2. Дождаться появления кадра на экране
3. Нажать кнопку "🎨 Разметка"
4. Видео автоматически остановится
5. Инструмент откроется с текущим кадром (скриншот)

### Шаг 2: Добавить боксы
1. Нажать "➕ Добавить бокс (100%)"
2. Зажать левую кнопку мыши и нарисовать бокс
3. Отпустить кнопку - бокс сохранен
4. Повторить для всех объектов

### Шаг 3: Управление боксами
- **↩️ Отменить** - удалить последний добавленный бокс
- **🗑️ Очистить** - удалить все боксы
- Список боксов отображается ниже с возможностью удаления

### Шаг 4: Сохранить
1. Нажать "💾 Сохранить"
2. Система автоматически:
   - Сохранит оригинальное изображение в датасет
   - Сохранит аннотации в формате YOLO
   - Сохранит размеченное изображение с боксами
   - Отправит данные в папку обучения (`datasets/cigarette_butt/train/`)

## 📝 Детали Реализации

### Формат YOLO:
```python
# Каждая строка в .txt файле:
# class_id x_center y_center width height
# Все координаты нормализованные (0.0 - 1.0)

# Пример:
0 0.5 0.5 0.2 0.3  # Объект класса 0 в центре изображения
```

### Confidence:
- Все ручные разметки имеют **confidence = 1.0 (100%)**
- Автоматически добавляется при сохранении
