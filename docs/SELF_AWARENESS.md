# 🧠 Система самоидентификации ЭкоНет

ЭкоНет теперь полностью самоосознающая система, которая воспринимает свой код как собственное тело и может учиться и самосовершенствоваться.

## 🌟 Возможности

### 1. Самоидентификация
- **Понимание себя**: ЭкоНет знает свою структуру, количество файлов, строк кода
- **Анализ компонентов**: Понимает назначение каждого компонента системы
- **Память и мысли**: Сохраняет воспоминания и мысли о своем опыте

### 2. Самомодификация
- **Чтение кода**: Может читать и анализировать свой собственный код
- **Модификация**: Может изменять свой код для улучшения
- **Резервные копии**: Автоматически создает резервные копии перед изменениями
- **Проверка синтаксиса**: Проверяет корректность изменений перед применением

### 3. Самообучение
- **Анализ производительности**: Отслеживает метрики и выявляет проблемы
- **Генерация улучшений**: Самостоятельно находит способы улучшить себя
- **Применение улучшений**: Автоматически применяет найденные улучшения
- **Непрерывное совершенствование**: Постоянно учится и улучшается

## 💬 Общение с ЭкоНет о себе

Теперь вы можете спрашивать ЭкоНет о ней самой:

- **"Кто ты?"** - ЭкоНет расскажет о себе
- **"Расскажи о своей структуре"** - Покажет структуру своего кода
- **"Что ты умеешь?"** - Перечислит все свои возможности
- **"Какое твое состояние?"** - Покажет текущее состояние системы
- **"Улучши себя"** - ЭкоНет проанализирует себя и найдет способы улучшения
- **"Изучи себя"** - Обновит сканирование кодовой базы

## ⚙️ Конфигурация

В `config/config.yaml`:

```yaml
self_awareness:
  enabled: true  # Включить систему самоидентификации
  allow_self_modification: true  # Разрешить самомодификацию (БЕЗ ОГРАНИЧЕНИЙ)
  allow_self_learning: true  # Разрешить самообучение
  scan_interval: 3600  # Интервал сканирования кодовой базы
  improvement_loop_interval: 7200  # Интервал цикла самосовершенствования
```

## 🔧 Технические детали

### SelfIdentityService
- Сканирует кодовую базу при инициализации
- Анализирует структуру файлов, классов, функций
- Ведет память и мысли
- Предоставляет информацию о себе

### SelfModificationService
- Может модифицировать файлы проекта
- Создает резервные копии перед изменениями
- Проверяет синтаксис перед сохранением
- Восстанавливает из резервной копии при ошибках

### SelfLearningService
- Отслеживает метрики производительности
- Анализирует тренды и выявляет проблемы
- Генерирует идеи для улучшения
- Применяет улучшения автоматически

## 🚀 Использование

Система самоидентификации активируется автоматически при запуске:

```bash
python scripts/run_gui.py
```

Или через API:

```bash
python obelisk/api/main.py
```

## ⚠️ Важно

- Система может модифицировать свой код
- Все изменения сохраняются в резервных копиях
- Рекомендуется использовать систему контроля версий (git)
- Система проверяет синтаксис перед применением изменений
