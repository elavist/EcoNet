# 🧠 Активное обучение - "Зародыш интеллекта"

## Что это?

Система автоматически учится во время просмотра видео! Это "зародыш интеллекта" - система сама улучшает себя.

## Как это работает?

### 1. Сбор неопределенных кадров
- Система находит детекции с уверенностью 0.3-0.7 (неопределенные)
- Сохраняет эти кадры в `data/raw/frames/`
- Сохраняет метаданные (координаты, уверенность)

### 2. Автоматическая разметка
- Модель автоматически размечает собранные кадры
- Создает YOLO аннотации (.txt файлы)
- Сохраняет в `data/labeled/`

### 3. Дообучение модели
- Когда накопится 100+ размеченных кадров
- Система автоматически дообучает модель (10 эпох)
- Проверяет улучшение качества

### 4. Автоматический деплой
- Если качество улучшилось на ≥1%
- Новая модель автоматически задеплоится
- Система продолжает работать с улучшенной моделью

## Использование

### Вариант 1: Тест с активным обучением

```powershell
# С IP Webcam
python scripts\test_with_active_learning.py --source 192.168.1.XXX

# С видеофайлом
python scripts\test_with_active_learning.py --source "video.mp4"

# С локальной камерой
python scripts\test_with_active_learning.py --source 0
```

### Вариант 2: Через основной скрипт

```powershell

python scripts\test_video_file.py "video.mp4" --active-learning
```

## Настройка

### config/config.yaml:

```yaml
active_learning:
  enabled: true  # Включить/выключить
  confidence_lower: 0.3  # Нижний порог для сбора
  confidence_upper: 0.7  # Верхний порог для сбора
  min_samples_for_retrain: 100  # Минимум кадров для дообучения
  retrain_epochs: 10  # Эпох для дообучения
  min_improvement: 0.01  # Минимум улучшения для деплоя (1%)
```

## Где хранятся данные

### Собранные кадры:
- `data/raw/frames/uncertain_*.jpg` - неопределенные кадры
- `data/raw/frames/highconf_*.jpg` - кадры с высокой уверенностью

### Размеченные данные:
- `data/labeled/*.jpg` - изображения
- `data/labeled/*.txt` - YOLO аннотации

### Модели:
- `models/cigarette_detector/active_learning_*/` - модели после дообучения
- `models/cigarette_detector/best.pt` - актуальная модель

## Статистика

Во время работы система ведет статистику:
- Количество собранных кадров
- Количество автоматически размеченных кадров
- Количество раундов дообучения

Проверить статистику можно через API:
```bash
curl http://localhost:8000/api/v1/system/status
```
