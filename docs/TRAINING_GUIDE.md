# 🎓 Руководство по обучению модели для >95% точности

## 🎯 Цель: Precision >= 95%

Текущая проблема: модель путает листья, иголки и другие объекты с окурками.

## ✅ Решение 1: Дообучение на полном датасете (9000+ фото)

### Запуск:
```powershell
python scripts\retrain_full_dataset.py
```

### Что делает:
- ✅ Использует ВСЕ 9000+ фото из датасета
- ✅ Обучение на 150 эпох (вместо 18)
- ✅ Оптимизированные параметры (AdamW, правильная аугментация)
- ✅ Автоматическая оценка и сравнение с предыдущей моделью
- ✅ Бэкап старой модели перед заменой

### Параметры обучения:
- **Эпохи:** 150 (достаточно для >95%)
- **Оптимизатор:** AdamW (лучше для дообучения)
- **Скорость обучения:** 0.0001 (низкая для тонкой настройки)
- **Аугментация:** Полная (mosaic, flip, HSV, rotation)
- **Early stopping:** Если нет улучшений 50 эпох

### Ожидаемый результат:
- Precision: **95%+** (с текущего уровня)
- mAP@0.5: **93%+**
- Меньше ложных срабатываний на листья, иголки

### Время:
- **CPU:** 4-6 часов
- **GPU:** 40-80 минут

## 🧠 Решение 2: Активное обучение ("Зародыш интеллекта")

Система автоматически учится во время просмотра видео!

### Как работает:

1. **Сбор неопределенных кадров:**
   - Система находит детекции с уверенностью 0.3-0.7
   - Сохраняет эти кадры для обучения

2. **Автоматическая разметка:**
   - Модель сама размечает собранные кадры
   - Создает YOLO аннотации

3. **Автоматическое дообучение:**
   - Когда накопится 100+ размеченных кадров
   - Система автоматически дообучает модель (10 эпох)

4. **Автоматический деплой:**
   - Если качество улучшилось на ≥1%
   - Новая модель автоматически задеплоится

### Запуск с активным обучением:

```powershell
# С IP Webcam
python scripts\test_with_active_learning.py --source 192.168.1.XXX

# На видеофайле
python scripts\test_video_file.py "video.mp4" --active-learning

# С локальной камерой
python scripts\test_with_webcam.py --ip 0 --conf 0.3 --active-learning
```

## 🔧 Дополнительные улучшения

### 1. Добавление негативных примеров

Соберите фото листьев, иголок, палочек и добавьте их в датасет БЕЗ аннотаций (пустые .txt файлы).

Это научит модель отличать окурки от похожих объектов.

### 2. Проверка качества разметки

Убедитесь что все 9000+ фото размечены корректно:
- Нет лишних аннотаций
- Все окурки размечены
- Правильные классы (1 = cig_butt)

### 3. Увеличение эпох

Если после 150 эпох Precision <95%:
- Увеличьте эпохи в `retrain_full_dataset.py` до 200-300
- Или запустите несколько раундов дообучения
