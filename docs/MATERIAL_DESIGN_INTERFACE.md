# Material Design Интерфейс ЭкоНет

## 🎨 Описание

Современный интерфейс в стиле **Material Design** - чистый, минималистичный дизайн без киберпанка.

## ✨ Особенности

### Цветовая палитра
- **Primary**: Синий (#2196F3) - основные действия
- **Secondary**: Оранжевый (#FF9800) - дополнительные действия
- **Success**: Зеленый (#4CAF50) - успешные операции
- **Error**: Красный (#F44336) - ошибки
- **Background**: Светло-серый (#FAFAFA) - фон
- **Surface**: Белый (#FFFFFF) - карточки и панели

### Компоненты

1. **MaterialButton** - кнопки в стиле Material Design
   - Варианты: primary, secondary, success, outlined
   - Плавные анимации при наведении
   - Скругленные углы (8px)

2. **MaterialCard** - карточки для группировки контента
   - Тени и границы
   - Заголовки
   - Скругленные углы (12px)

3. **Современная типографика**
   - Шрифт: Segoe UI
   - Размеры: 11px (обычный), 12px (кнопки), 14px (текст), 16px (заголовки)

## 🚀 Использование

### Запуск
```bash
python -m obelisk.ui.gui_material
```

Или через батник (Windows):
```bash
ЗАПУСТИТЬ_ЭКОНЕТ.bat
```

## 🎯 Преимущества

1. **Современный дизайн** - соответствует Material Design Guidelines
2. **Чистый интерфейс** - без киберпанка, минималистичный
3. **Удобство использования** - интуитивно понятный
4. **Профессиональный вид** - подходит для демонстрации
5. **Адаптивность** - легко настраивается

## 🔧 Настройка

Цвета и стили настраиваются в словаре `MATERIAL_THEME` в начале файла `gui_material.py`.
