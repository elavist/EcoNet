# ✅ Инструмент Ручной Разметки - Итоговая Реализация

## 🎯 Реализованный Функционал

### 1. ✅ Метод Очистки Кэша (`CacheManager`)
- Очистка кэша детекций
- Очистка кэша датасетов (.cache файлы)
- Очистка временных файлов (__pycache__)
- Полная очистка через UI кнопку "🧹 Очистить кэш"

### 2. ✅ Выбор Модели (`ModelSelector`)
- Получение списка доступных моделей из сохраненных версий обучения
- Выбор модели с автоматическим копированием как best.pt
- Резервное копирование текущей модели
- UI для выбора модели через кнопку "📦 Выбрать модель"

### 3. ✅ Инструмент Ручной Разметки (`AnnotationTool` + `AnnotationWidget`)

#### AnnotationTool (`obelisk/services/annotation_tool.py`):
- `save_annotation()` - сохранение аннотации в формате YOLO
- `add_label()` - быстрое добавление метки
- Автоматическое копирование в датасет для обучения
- Сохранение оригинала и размеченного изображения

#### AnnotationWidget (`obelisk/ui/annotation_widget.py`):
- Рисование боксов мышью (drag & drop)
- Отображение всех добавленных боксов
- Управление боксами (удаление, отмена)
- Сохранение с confidence 100%

### 4. ✅ Быстрое Добавление Метки из Кадра
- Кнопка "🏷️ Добавить метку" в UI
- Автоматическое использование детекций из текущего кадра
- Сохранение с confidence 100%
- Готово для обучения

## 🔧 Формат Сохранения

### YOLO формат аннотаций:
```
# Файл: datasets/cigarette_butt/train/labels/image_20251120_123456.txt
0 0.5 0.5 0.2 0.3
0 0.7 0.3 0.15 0.25
```

Формат: `class_id x_center y_center width height` (все нормализованные)

### Изображения:
- **Оригинал:** `datasets/cigarette_butt/train/images/{name}_{timestamp}.jpg`
- **С боксами:** `datasets/cigarette_butt/train/images/{name}_{timestamp}_annotated.jpg`
