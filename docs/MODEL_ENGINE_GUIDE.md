# Движок объединения моделей (ModelEngine)

## Описание

`ModelEngine` - это унифицированная система для работы с несколькими моделями детекции, позволяющая:
- Загружать несколько моделей одновременно
- Объединять результаты детекции через ансамбль
- Создавать единую модель из нескольких источников
- Оптимизировать производительность

## Возможности

### 1. Загрузка нескольких моделей
Движок может загружать несколько моделей YOLO одновременно:
- Поддержка PT и ONNX форматов
- Автоматический выбор оптимального формата
- Индивидуальные веса для каждой модели

### 2. Методы объединения (с улучшенной математикой)

#### Weighted Voting (Взвешенное голосование) ⭐ Рекомендуется
- **IoU группировка**: Использует Intersection over Union для точной группировки перекрывающихся детекций
- **Динамические веса**: Веса моделей автоматически корректируются на основе их исторической производительности
  ```python
  effective_weight = base_weight × reliability_factor
  reliability_factor = 0.8 + (avg_confidence × 0.4)
  ```
- **Комбинированное взвешивание**: Учитывает как вес модели, так и уверенность детекции
  ```python
  conf_weight = model_weight × detection_confidence
  weighted_bbox = Σ(bbox × conf_weight) / Σ(conf_weight)
  ```
- **Голосование по классам**: Класс определяется большинством взвешенных голосов

#### Majority Voting (Голосование большинством)
- **IoU группировка**: Точная группировка перекрывающихся детекций
- Детекция считается валидной если несколько моделей согласны (IoU >= threshold)
- Минимальное количество согласных моделей настраивается
- Использует детекцию с максимальной уверенностью из кластера

#### Average Voting (Усреднение)
- **IoU группировка**: Группировка по перекрытию детекций
- Простое усреднение детекций в каждом кластере
- Голосование большинством для определения класса
- Подходит для моделей с похожей точностью

### 3. Статистика
Движок отслеживает статистику по каждой модели:
- Количество обработанных кадров
- Количество детекций
- Средняя уверенность
- Время последнего обновления

## Конфигурация

Добавьте в `config/config.yaml`:

```yaml
model_engine:
  ensemble:
    enabled: true
    voting_method: "weighted"  # weighted, majority, average
    min_models_agree: 2  # Минимум моделей для согласия
    iou_threshold: 0.5  # Порог IoU для группировки детекций (0.0-1.0)
  models:
    - name: "primary"
      path: "models/cigarette_detector/best.pt"
      weight: 1.0
      enabled: true
    - name: "secondary"
      path: "models/cigarette_detector/best_v2.pt"
      weight: 0.8
      enabled: true
```

## Использование

```python
from obelisk.core.model_engine import ModelEngine
import yaml

# Загрузка конфигурации
with open('config/config.yaml', 'r') as f:
    config = yaml.safe_load(f)

# Создание движка
engine = ModelEngine(config)

# Детекция на кадре
detections = await engine.detect_frame(frame)

# Получение статистики
stats = engine.get_statistics()
```

## API

### `detect_frame(frame, frame_id=None)`
Детекция на кадре с использованием всех моделей

### `get_statistics()`
Получить статистику по всем моделям

### `add_model(name, model_path, weight=1.0)`
Добавить новую модель в движок

### `remove_model(name)`
Удалить модель из движка

### `set_model_weight(name, weight)`
Установить вес модели

## Улучшенная Математика

### IoU (Intersection over Union) Группировка

Вместо простого округления координат система использует **IoU** для точной группировки перекрывающихся детекций от разных моделей:

```python
IoU = Intersection(bbox1, bbox2) / Union(bbox1, bbox2)

# Детекции с IoU >= threshold группируются вместе
# Обеспечивает правильное объединение даже при небольших различиях в координатах
```

### Динамические Веса Моделей

Система автоматически корректирует веса моделей на основе их исторической производительности:

```python
# Базовый вес из конфигурации
base_weight = 1.0

# Фактор надежности на основе статистики
reliability_factor = 0.8 + (avg_confidence × 0.4)
# Если модель показала высокую среднюю уверенность, её вес увеличивается

# Итоговый эффективный вес
effective_weight = base_weight × reliability_factor
```

### Комбинированное Взвешивание

При объединении детекций учитываются оба фактора:

```python
# Комбинированный вес: вес модели × уверенность детекции
conf_weight = model_weight × detection_confidence

# Взвешенное усреднение координат
weighted_bbox[i] = Σ(bbox[i] × conf_weight) / Σ(conf_weight)

# Взвешенная уверенность
weighted_conf = Σ(confidence × conf_weight) / Σ(conf_weight)
```

Это обеспечивает:
- **Высокоуверенные детекции** имеют больший вес даже от моделей с меньшим базовым весом
- **Надежные модели** имеют больший вес для всех своих детекций
- **Баланс** между качеством модели и качеством конкретной детекции

## Преимущества

1. **Высокая точность**: IoU группировка обеспечивает правильное объединение детекций
2. **Адаптивность**: Динамические веса автоматически корректируются на основе производительности
3. **Надежность**: Если одна модель ошибается, другие компенсируют благодаря взвешенному голосованию
4. **Гибкость**: Легко добавлять/удалять модели без изменения логики
5. **Оптимизация**: Можно использовать быстрые модели для предварительной фильтрации
6. **Интеллектуальное объединение**: Комбинированное взвешивание учитывает качество модели и качество детекции
