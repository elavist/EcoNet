# ⚡ Руководство по оптимизации FPS

## 🎯 Цель: Максимальная скорость обработки видео

## 📊 Текущая производительность

Проверьте текущий FPS:
```powershell
python scripts\test_fps.py --source 0 --duration 30
```

## 🚀 Способы повышения FPS

### 1. Уменьшить размер входного изображения

**Самый простой способ повысить FPS в 2-3 раза!**

```yaml
# config/config.yaml
model:
  input_size: 416  # Вместо 640
```

**Сравнение:**
- **640x640**: Лучшая точность, медленнее (~10-15 FPS на CPU)
- **416x416**: Баланс скорости и точности (~20-30 FPS на CPU) ⭐ **РЕКОМЕНДУЕТСЯ**
- **320x320**: Максимальная скорость, меньше точность (~30-40 FPS на CPU)

**Использование:**
```powershell
# В тестах можно указать размер:
python scripts\test_with_webcam.py --ip 0 --conf 0.3
# Затем в коде изменить input_size
```

---

### 2. Использовать GPU (если доступно)

**GPU дает ускорение в 5-10 раз!**

```yaml
# config/config.yaml
edge:
  device: cuda:0  # Вместо cpu
```

**Проверка доступности GPU:**
```python
python -c "import torch; print('CUDA доступен:', torch.cuda.is_available())"
```

**Если GPU доступен:**
- Измените `edge.device` на `cuda:0`
- Перезапустите детектор
- Ожидайте FPS: **50-100+** на GPU

---

### 3. Экспорт модели в ONNX

**ONNX быстрее PyTorch на 20-30%**

```powershell
python scripts\optimize_for_fps.py
```

Это:
- Экспортирует модель в ONNX
- Создаст оптимизированную конфигурацию
- Покажет рекомендации

**Использование ONNX модели:**
```python
model = YOLO('models/cigarette_detector/best.onnx')  # Вместо .pt
```

---

### 4. Уменьшить max_detections

**Меньше детекций = быстрее NMS**

```yaml
# config/config.yaml
model:
  max_detections: 50  # Вместо 300
```

Для окурков обычно достаточно 50 детекций на кадр.

---

### 5. Пропускать кадры (Skip Frames)

**Обрабатывать каждый N-й кадр**

Добавьте в код:
```python
frame_skip = 2  # Обрабатывать каждый 2-й кадр
if frame_count % frame_skip != 0:
    continue  # Пропустить кадр
```

**Результат:**
- FPS увеличится в 2 раза при `frame_skip=2`
- Точность практически не изменится
- Визуально незаметно

---

### 6. Уменьшить inference_interval

```yaml
# config/config.yaml
edge:
  inference_interval: 0.0  # Минимальный интервал (максимум FPS)
```

Было: `0.1` секунды = ~10 FPS максимум
Стало: `0.0` = без ограничений

---

### 7. Использовать более легкую модель

Если точность позволяет:
- **yolov8n** (nano) - самый быстрый
- **yolov8s** (small) - баланс
- Текущая: yolov8n (уже оптимальна)

## 💡 Практические рекомендации

1. **Начните с уменьшения input_size до 416**
   - Легко, сразу дает 2x ускорение
   - Точность практически не меняется

2. **Используйте GPU если есть**
   - Измените `edge.device = cuda:0`
   - Это даст максимальное ускорение

3. **Экспортируйте в ONNX**
   - Один раз выполните `optimize_for_fps.py`
   - Используйте ONNX модель дальше

4. **Пропускайте кадры если нужно**
   - Для видеонаблюдения достаточно 10-15 FPS
   - Пропуск каждого 2-го кадра = 2x ускорение
