# 🧠 ИЕРАРХИЯ НЕЙРОНОВ ЭКОНЕТ

**Обновлено:** 2025-11-22  
**Статус:** ✅ Актуально - Система полностью функциональна

## 📊 Общая Структура

Система ЭкоНет использует **многоуровневую нейронную архитектуру** с двумя основными уровнями:

1. **Базовый уровень** (4 узла) - простая архитектура для базовой функциональности
2. **Расширенный уровень** (10+ нейронов) - полная нейронная сеть с разными типами нейронов

---

## 🏗️ Уровень 1: Базовая Архитектура (4 узла)

Используется в `NeuralNetworkArchitecture` (`obelisk/core/neural_nodes.py`)

### Структура:

```
                    ┌─────────────────────┐
                    │  Information Hub    │
                    │   (Центральный)     │
                    └──────────┬──────────┘
                               │
           ┌───────────────────┼───────────────────┐
           │                   │                   │
           ▼                   ▼                   ▼
    ┌──────────┐      ┌──────────┐      ┌──────────┐
    │  YOLO    │      │ DeepSeek │      │Coordinator│
    │  Neuron  │      │  Neuron  │      │  Neuron   │
    └────┬─────┘      └────┬─────┘      └────┬─────┘
         │                 │                 │
         └─────────────────┼─────────────────┘
                           │
                    (прямые связи)
```

### 1. YOLO-Нейрон (`yolo_neuron`)
**Роль**: Визуальное восприятие  
**Тип**: Perception  
**Соединения**:
- → `information_hub` (data) - отправка детекций
- ← `information_hub` (feedback) - получение команд
- → `deepseek_neuron` (data) - отправка детекций для анализа
- ← `coordinator_neuron` (signal) - управление детекцией

**Функции**:
- Обработка кадров видео
- Детекция объектов (мусор, окурки)
- Отправка результатов детекции

### 2. DeepSeek-Нейрон (`deepseek_neuron`)
**Роль**: Анализ и принятие решений (LLM)  
**Тип**: Analysis  
**Статус**: ⚠️ Не используется на данном этапе (llm_engine=None)

**Соединения**:
- → `information_hub` (data) - отправка результатов анализа
- ← `information_hub` (feedback) - получение контекста
- ← `yolo_neuron` (data) - получение детекций для анализа
- → `coordinator_neuron` (signal) - отправка команд управления

### 3. Coordinator-Нейрон (`coordinator_neuron`)
**Роль**: Координация задач  
**Тип**: Coordination  
**Соединения**:
- → `information_hub` (data) - отправка информации о задачах
- ← `information_hub` (feedback) - получение контекста
- ← `deepseek_neuron` (signal) - получение команд управления
- → `yolo_neuron` (signal) - управление детекцией

**Функции**:
- Управление задачами
- Распределение задач между компонентами
- Координация работы системы

### 4. Information Hub (`information_hub`)
**Роль**: Центральный узел синхронизации  
**Тип**: Communication  
**Соединения**:
- ← `yolo_neuron` (data) - получение детекций
- ← `deepseek_neuron` (data) - получение результатов анализа
- ← `coordinator_neuron` (data) - получение информации о задачах
- → `yolo_neuron` (feedback) - отправка команд
- → `deepseek_neuron` (feedback) - отправка контекста
- → `coordinator_neuron` (feedback) - отправка контекста

**Функции**:
- Централизованное хранение информации
- Синхронизация данных между нейронами
- Маршрутизация сообщений
- Обеспечение согласованности данных

### Всего связей: 9
1. `yolo_neuron` → `information_hub` (data)
2. `deepseek_neuron` → `information_hub` (data)
3. `coordinator_neuron` → `information_hub` (data)
4. `information_hub` → `yolo_neuron` (feedback)
5. `information_hub` → `deepseek_neuron` (feedback)
6. `information_hub` → `coordinator_neuron` (feedback)
7. `yolo_neuron` → `deepseek_neuron` (data)
8. `deepseek_neuron` → `coordinator_neuron` (signal)
9. `coordinator_neuron` → `yolo_neuron` (signal)

## 🏗️ Уровень 2: Расширенная Архитектура (10+ нейронов)

Используется в `NeuralNetworkBuilder` (`obelisk/brain/neural_network_builder.py`)

### Иерархия по типам:

```
┌─────────────────────────────────────────────────────────┐
│                  КОЛЛЕКТИВНЫЙ РАЗУМ                      │
│              (CollectiveMind)                            │
└─────────────────────────────────────────────────────────┘
                            │
        ┌───────────────────┼───────────────────┐
        │                   │                   │
        ▼                   ▼                   ▼
┌──────────────┐   ┌──────────────┐   ┌──────────────┐
│  ВОСПРИЯТИЕ  │   │  КООРДИНАЦИЯ │   │  ПАМЯТЬ      │
│ (Perception) │   │(Coordination)│   │  (Memory)    │
└──────────────┘   └──────────────┘   └──────────────┘
        │                   │                   │
        ▼                   ▼                   ▼
┌──────────────┐   ┌──────────────┐   ┌──────────────┐
│  КОММУНИКАЦИЯ│   │  ОБУЧЕНИЕ    │   │  АНАЛИЗ      │
│(Communication)│   │ (Learning)  │   │  (Analysis)  │
└──────────────┘   └──────────────┘   └──────────────┘
```

### 1. Нейроны Восприятия (Perception)

#### 1.1. Vision Neuron (`vision_neuron`)
**Роль**: Визуальное восприятие  
**Соединения**:
- → `hub_neuron` (data) - отправка визуальных данных

**Функции**:
- Получение кадров видео
- Предобработка изображений
- Управление визуальным контекстом

#### 1.2. Detection Neuron (`detection_neuron`)
**Роль**: Детекция объектов  
**Соединения**:
- → `hub_neuron` (data) - отправка детекций

**Функции**:
- Детекция объектов (YOLO)
- Обработка результатов детекции
- Использование GPU через ModelEngine

#### 1.3. Tracking Neuron (`tracking_neuron`)
**Роль**: Отслеживание объектов  
**Соединения**:
- Подключен к GPU системе (венозная система)

**Функции**:
- Отслеживание объектов во времени
- Управление траекториями
- Использование GPU для ускорения

### 2. Нейроны Координации (Coordination)

#### 2.1. Task Coordinator Neuron (`task_coordinator_neuron`)
**Роль**: Координация задач  
**Соединения**:
- ← `hub_neuron` (data) - получение данных
- → `hub_neuron` (feedback) - отправка информации о задачах
- → `swarm_coordinator_neuron` (data) - распределение задач

**Функции**:
- Создание и управление задачами
- Приоритизация задач
- Распределение задач

#### 2.2. Swarm Coordinator Neuron (`swarm_coordinator_neuron`)
**Роль**: Координация роя роботов  
**Соединения**:
- ← `task_coordinator_neuron` (data) - получение задач
- → `hub_neuron` (feedback) - отправка статуса роя

**Функции**:
- Управление роем роботов
- Распределение задач между роботами
- Мониторинг статуса роботов (через MQTT)

#### 2.3. Docker Neuron (`docker_neuron`)
**Роль**: Управление Docker контейнерами  
**Функции**:
- Управление контейнерами
- Мониторинг состояния контейнеров

### 3. Нейроны Памяти (Memory)

#### 3.1. Experience Neuron (`experience_neuron`)
**Роль**: Долгосрочная память  
**Соединения**:
- ← `hub_neuron` (data) - получение данных для сохранения

**Функции**:
- Сохранение опыта в базу данных
- Извлечение исторических данных
- Управление долгосрочной памятью

#### 3.2. Short Term Memory Neuron (`short_term_memory_neuron`)
**Роль**: Краткосрочная память  
**Соединения**:
- ← `hub_neuron` (data) - получение данных для кеширования

**Функции**:
- Временное хранение данных
- Кеширование недавних событий
- Быстрый доступ к актуальной информации

### 4. Нейроны Коммуникации (Communication)

#### 4.1. Hub Neuron (`hub_neuron`)
**Роль**: Центральный хаб коммуникации  
**Соединения**:
- ← `detection_neuron` (data)
- ← `vision_neuron` (data)
- → `task_coordinator_neuron` (data)
- ← `task_coordinator_neuron` (feedback)
- ← `swarm_coordinator_neuron` (feedback)
- → `experience_neuron` (data)
- → `short_term_memory_neuron` (data)
- → `active_learning_neuron` (data)
- → `analyzer_neuron` (data)
- → `mqtt_neuron` (data)
- ← `mqtt_neuron` (data)

**Функции**:
- Централизованная маршрутизация сообщений
- Синхронизация данных
- Координация взаимодействий между нейронами

#### 4.2. MQTT Neuron (`mqtt_neuron`)
**Роль**: Внешняя коммуникация через MQTT  
**Соединения**:
- ↔ `hub_neuron` (data) - двусторонняя связь

**Функции**:
- Коммуникация с роботами через MQTT
- Публикация статуса системы
- Подписка на события от роботов

### 5. Нейроны Обучения (Learning)

#### 5.1. Active Learning Neuron (`active_learning_neuron`)
**Роль**: Активное обучение  
**Соединения**:
- ← `hub_neuron` (data) - получение данных для обучения

**Функции**:
- Выбор наиболее информативных примеров
- Разметка данных
- Обновление модели

### 6. Нейроны Анализа (Analysis)

#### 6.1. Analyzer Neuron (`analyzer_neuron`)
**Роль**: Анализ данных  
**Соединения**:
- ← `hub_neuron` (data) - получение данных для анализа

**Функции**:
- Анализ паттернов
- Статистический анализ
- Выявление аномалий

## 📈 Иерархия Важности

1. **Уровень 0: Коллективный Разум**
   - Управляет всей системой
   - Координирует все нейроны

2. **Уровень 1: Центральные Нейроны**
   - `hub_neuron` - центральная точка коммуникации
   - `task_coordinator_neuron` - координация задач

3. **Уровень 2: Специализированные Нейроны**
   - Perception нейроны (Vision, Detection, Tracking)
   - Coordination нейроны (Swarm Coordinator, Docker)
   - Memory нейроны (Experience, Short Term)

4. **Уровень 3: Вспомогательные Нейроны**
   - Learning нейроны (Active Learning)
   - Analysis нейроны (Analyzer)
   - Communication нейроны (MQTT)

---

## 🔗 Типы Связей

1. **data** - передача данных (детекции, задачи, события)
2. **feedback** - обратная связь (команды, статус)
3. **signal** - управляющие сигналы (включить/выключить, изменить параметры)

## 📊 Статистика

### Базовый уровень:
- **4 узла**: yolo, deepseek, coordinator, information_hub
- **9 связей**: 3 к Hub, 3 от Hub, 3 прямые

### Расширенный уровень:
- **10+ нейронов** по категориям
- **20+ связей** между нейронами
- **6 категорий**: Perception, Coordination, Memory, Communication, Learning, Analysis

## 🔧 Интеграция с GPU (Венозная Система)

Нейроны, использующие GPU:
- `detection_neuron` - через ModelEngine
- `tracking_neuron` - через GPU Circulatory System
- Все нейроны могут использовать GPU через `gpu_distributor`

---

## 📝 Регистрация в Коллективном Разуме

Все нейроны регистрируются в `CollectiveMind`:
- Отслеживание состояния
- Координация работы
- Синхронизация данных
- Мониторинг здоровья системы
