# ✅ Очистка Кэша и Выбор Модели

## 🎯 Реализованный Функционал

### 1. ✅ Метод Очистки Кэша (`CacheManager`)

**Файл:** `obelisk/services/cache_manager.py`

**Методы:**
- `clear_detection_cache()` - очистка кэша детекций в UnifiedEngine
- `clear_dataset_cache()` - очистка кэша датасетов (.cache файлы)
- `clear_temp_files()` - очистка временных файлов (__pycache__)
- `clear_all_cache()` - полная очистка всего кэша

### 2. ✅ Выбор Модели (`ModelSelector`)

**Файл:** `obelisk/services/model_selector.py`

**Методы:**
- `get_available_models()` - получение списка доступных моделей из сохраненных версий
- `select_model()` - выбор модели и копирование её как best.pt
- `get_model_info()` - получение информации о модели

**Источники моделей:**
- `models/cigarette_detector/best.pt` (текущая)
- `models/cigarette_detector/train/weights/best.pt`
- `models/cigarette_detector/train/weights/last.pt`
- `models/cigarette_detector/retrain_full/weights/best.pt`
- `models/cigarette_detector/retrain_full/weights/last.pt`
- Другие модели из папок обучения

### 3. ✅ UI для Выбора Модели и Очистки Кэша

**Файл:** `obelisk/ui/gui_material.py`

**Добавлено:**
- Панель "Выбор модели" с кнопками:
  - 📦 Выбрать модель
  - 🧹 Очистить кэш

**Функции:**
- `show_model_selector()` - показать диалог выбора модели
- `_select_model()` - выбрать модель и применить
- `clear_cache()` - очистить кэш системы

## 🔧 Использование

### Очистка кэша:
1. Нажать кнопку "🧹 Очистить кэш"
2. Подтвердить очистку
3. Система очистит:
   - Кэш детекций
   - Кэш датасетов (.cache файлы)
   - Временные файлы (__pycache__)

### Выбор модели:
1. Нажать кнопку "📦 Выбрать модель"
2. Выбрать модель из списка
3. Подтвердить выбор
4. Текущая модель будет сохранена в backups
5. Выбранная модель скопирована как best.pt
6. Перезапустить программу для применения

## 🧹 Скрипт Очистки Проекта

**Файл:** `scripts/clean_project.py`

**Функции:**
- Очистка всех __pycache__ директорий
- Очистка всех .pyc файлов
- Очистка .cache файлов (кроме YOLOv8-main)

**Использование:**
```bash
python scripts/clean_project.py
```

## 📝 Примечания

- При выборе модели текущая модель автоматически сохраняется в backups
- Модели отсортированы по дате изменения (новые первыми)
- Очистка кэша не удаляет важные данные (модели, видео, детекции)
- Скрипт очистки проекта игнорирует YOLOv8-main (внешняя библиотека)
