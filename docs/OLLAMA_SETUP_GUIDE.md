# 🏠 Настройка Ollama для ЭкоНет (Локальный режим)

## Установка Ollama

### Вариант 1: Установка на ПК (РЕКОМЕНДУЕТСЯ)

**Windows:**
1. Скачайте установщик: https://ollama.ai/download
2. Запустите `OllamaSetup.exe`
3. Установите в стандартную папку (обычно `C:\Users\ВашеИмя\AppData\Local\Programs\Ollama`)
4. Ollama автоматически добавится в PATH

**Преимущества:**
- ✅ Автоматический запуск при старте системы
- ✅ Легко обновлять
- ✅ Интеграция с системой

### Вариант 2: Портативная версия (exe в корне проекта)

**Если хотите локально в проекте:**
1. Скачайте portable версию Ollama (если доступна)
2. Создайте папку `tools/ollama/` в корне проекта
3. Распакуйте туда
4. Запускайте вручную: `tools/ollama/ollama.exe serve`

**Недостатки:**
- ⚠️ Нужно запускать вручную каждый раз
- ⚠️ Сложнее обновлять

**Рекомендация:** Используйте вариант 1 (установка на ПК)

## Первый запуск

### 1. Запуск Ollama сервера

**Если установлен на ПК:**
```powershell
# Ollama должен запуститься автоматически
# Проверьте: откройте браузер на http://localhost:11434
```

**Если не запустился автоматически:**
```powershell
ollama serve
```

### 2. Скачивание модели

**Рекомендуемые модели для ЭкоНет:**

```powershell
# Быстрая и эффективная (рекомендуется для начала)
ollama pull llama3.1:8b

# Или более мощная (если есть ресурсы)
ollama pull llama3.1:70b

# Альтернатива - хорошая поддержка русского
ollama pull mistral:7b

# Еще одна хорошая для русского
ollama pull qwen2.5:7b
```

**Рекомендация для начала:** `llama3.1:8b` - хороший баланс скорости и качества

## Настройка ЭкоНет для Ollama

### Автоматическая настройка:

```powershell
python scripts\setup_llm.py
# Выберите вариант 2 (Ollama)
```

### Ручная настройка:

Откройте `config/config.yaml` и установите:

```yaml
chat:
  enabled: true
  use_llm: true
  llm_provider: "ollama"
  llm_model: "llama3.1:8b"  # Или другая модель
  llm_api_key: null  # Не нужен для Ollama
  max_history: 50
```

## Устранение проблем

### Ollama не запускается

```powershell
# Проверьте что Ollama установлен
ollama --version

# Запустите вручную
ollama serve

# Проверьте порт
netstat -an | findstr 11434
```

### Модель не найдена

```powershell
# Проверьте установленные модели
ollama list

# Если модели нет - скачайте
ollama pull llama3.1:8b
```

### ЭкоНет не подключается к Ollama

1. Убедитесь что Ollama запущен: `ollama serve`
2. Проверьте URL в конфиге (должен быть `http://localhost:11434`)
3. Проверьте название модели в конфиге
4. Перезапустите ЭкоНет

### Медленные ответы

- Используйте меньшую модель: `llama3.1:8b` вместо `70b`
- Закройте другие приложения
- Убедитесь что есть достаточно RAM (минимум 8GB для 8b модели)
