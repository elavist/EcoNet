## GPU Test Manager

### Отдельный блок для тестов

Тесты имеют отдельный GPU Manager (`obelisk/core/gpu_test_manager.py`), который:

- Позволяет тестам использовать GPU **параллельно** с основной системой
- Не конфликтует с основной системой ЭКОНЕТ
- Автоматически очищает память после тестов
- Проверяет доступность GPU перед запуском тестов

### Использование в тестах

```python
# В conftest.py автоматически инициализируется gpu_test_manager
@pytest.fixture
async def unified_engine(test_config, gpu_test_manager):
    # Тесты автоматически получают доступ к GPU
    # gpu_test_manager управляет GPU для тестов
    ...
```

### Ручное использование

```python
from obelisk.core.gpu_test_manager import get_test_gpu_manager

# Получить GPU Manager для тестов
test_gpu = get_test_gpu_manager(device_id=0)

# Проверить доступность GPU
if test_gpu.reserve_gpu_for_tests():
    # Тесты могут использовать GPU
    ...

# Очистка после тестов
test_gpu.cleanup()
```

## Тесты

### Автоматическая интеграция

Тесты автоматически получают доступ к GPU через `gpu_test_manager`:

1. **Фикстура gpu_test_manager**: Автоматически инициализируется в `conftest.py`
2. **Резервирование GPU**: Проверяет доступность GPU перед тестами
3. **Параллельная работа**: Тесты и основная система могут работать одновременно
4. **Автоматическая очистка**: Память GPU очищается после каждого теста

### Запуск тестов

```bash
# Тесты автоматически получат доступ к GPU
pytest tests/ -v

# Тесты будут использовать GPU параллельно с основной системой
# Если GPU доступен (≥1 GB свободно)
```
