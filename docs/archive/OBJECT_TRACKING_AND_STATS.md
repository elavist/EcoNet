### 4. Трекинг объектов с порогом 86% (IoU > 0.86)

**Создан модуль `obelisk/core/object_tracker.py`:**

#### `ObjectTracker` класс:
- **Порог совпадения:** IoU > 0.86 (86%)
- **Максимум пропущенных кадров:** 5 (настраивается)
- **Жадное сопоставление:** Сопоставление детекций с существующими треками по максимальному IoU
- **Предсказание позиции:** Простая линейная экстраполяция для лучшего сопоставления
- **Сглаживание:** Средняя позиция объекта из истории (до 10 кадров)

#### `TrackedObject` класс:
- **track_id:** Уникальный ID трека
- **bbox:** Текущая позиция [x, y, w, h]
- **confidence:** Уверенность детекции
- **bbox_history:** История позиций (последние 10 кадров)
- **frames_count:** Количество кадров с объектом
- **Средняя позиция:** Сглаженная позиция для стабильности

#### Методы:
- **`update(detections, frame_number)`** - Обновление трекеров на основе детекций
- **`calculate_iou(box1, box2)`** - Вычисление IoU между боксами
- **`get_track_statistics()`** - Статистика треков
- **`reset()`** - Сброс трекера

**Логика трекинга:**
1. Вычисление IoU между существующими треками и новыми детекциями
2. Сопоставление по максимальному IoU (если > 0.86)
3. Обновление существующих треков или создание новых
4. Удаление треков, пропущенных более 5 кадров

### 5. Кэширование треков для экономии ресурсов

**Экономия ресурсов:**
- ✅ Не нужно детектировать объект заново на каждом кадре
- ✅ Используется предсказание позиции для сопоставления
- ✅ Треки удаляются только после нескольких пропущенных кадров
- ✅ История позиций для сглаживания и предсказания

**Преимущества:**
- 🚀 Экономия ресурсов на повторной детекции
- 📊 Стабильное отслеживание объектов между кадрами
- 🎯 Более точное сопоставление с порогом 86%
- 💾 Сохранение истории позиций для анализа

## 📊 Структура статусов

### Блок "Статус системы":

1. **"Модель"** - Статус модели (Инициализация... / Готов)
2. **"Видео"** - Текущее видео (Не подключено / Название файла)

4. **"Кадров"** - Количество кадров с детекциями (0 кадров / 120 кадров)
5. **"FPS"** - Текущий FPS (0 / 60)
6. **"Детекций"** - Общее количество детекций (0 / 450)

## 🔄 Рабочий процесс

### Обработка видео:
1. Импорт видео → копирование в `data/media/videos/`
2. Автоматическая обработка → YOLO обрабатывает все кадры
3. Трекинг объектов → сопоставление объектов между кадрами (IoU > 0.86)
4. Сохранение детекций → в `data/media/detections/{file_id}_detections.pkl`
5. Обновление статистики → "Обработано", "Кадров", "Детекций"

### Воспроизведение:
1. Загрузка видео → проверка `processed: true`
2. Если не обработано → показывается предупреждение
3. Если обработано → загрузка сохраненных детекций
4. Воспроизведение → отображение детекций с track_id

## 🚀 Использование трекера

```python
from obelisk.core.object_tracker import ObjectTracker

# Создание трекера
tracker = ObjectTracker(iou_threshold=0.86, max_missed_frames=5)

# Обновление трекеров на каждом кадре
detections = [
    {"bbox": [100, 100, 50, 50], "confidence": 0.9, "class": 0},
    {"bbox": [200, 200, 50, 50], "confidence": 0.85, "class": 0}
]

tracked_detections = tracker.update(detections, frame_number=1)

# Каждая детекция теперь имеет track_id
for det in tracked_detections:
    print(f"Track ID: {det['track_id']}, Tracked: {det['tracked']}")
```
