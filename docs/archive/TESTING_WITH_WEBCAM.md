# Тестирование системы с IP Webcam

## 📱 Подготовка телефона

### Шаг 1: Установка IP Webcam

1. Установите приложение **IP Webcam** на Android (или iOS аналог)
2. Запустите приложение

### Шаг 2: Настройка IP Webcam

1. В приложении IP Webcam:
   - Нажмите **"Start server"**
   - Запишите IP адрес и порт (например: `192.168.1.100:8080`)
   - Убедитесь, что телефон и компьютер в одной Wi-Fi сети

2. **Важно:** В настройках IP Webcam включите:
   - ✅ "Video preferences" → выберите разрешение (например, 640x480 для скорости)
   - ✅ "Streaming" → включите MJPEG или RTSP

## 🎯 Быстрый тест БЕЗ обучения

Можно сразу протестировать с **предобученной моделью** (хотя она не обучена на окурках, но покажет как работает система):

```bash
python scripts/test_with_webcam.py --ip 192.168.1.100
```

Замените `192.168.1.100` на IP адрес вашего телефона.

**Ожидаемый результат:**
- ✅ Система подключится к камере
- ✅ Будет работать детекция (но может не находить окурки, т.к. модель не обучена)
- ✅ Вы увидите видео с bounding boxes (если что-то найдет)

## 🎓 Обучение модели на вашем датасете

Для **реальной детекции окурков** нужно обучить модель:

### Вариант 1: Быстрое обучение (для теста)

```bash
# Обучение на небольшое количество эпох для быстрого теста
python scripts/train_model.py
```

Но нужно обновить скрипт, чтобы можно было указать меньше эпох. Или обучить вручную:

```bash
cd models/cigarette_detector
yolo task=detect mode=train model=yolov8n.pt data=data.yaml epochs=10 imgsz=640 batch=16
```

### Вариант 2: Полное обучение (рекомендуется)

```bash
# Сначала настройте датасет
python scripts/setup_dataset.py

# Затем обучите модель (займет время)
python scripts/train_model.py
```

Это займет:
- **CPU:** ~2-4 часа для 50 эпох
- **GPU:** ~20-30 минут для 50 эпох

## 🧪 Тестирование после обучения

После обучения модели:

1. **Проверьте, что модель создана:**
```bash
ls models/cigarette_detector/best.pt
# Или
ls data/models/*.pt
```

2. **Обновите конфигурацию** (если нужно):
```yaml
# config/config.yaml
model:
  weights_path: "models/cigarette_detector/best.pt"  # или путь к вашей модели
```

3. **Запустите тест:**
```bash
python scripts/test_with_webcam.py --ip 192.168.1.100
```

## 🔧 Решение проблем

### Проблема: "Не удалось подключиться к IP Webcam"

**Решение:**
1. ✅ Проверьте, что телефон и компьютер в одной Wi-Fi сети
2. ✅ Убедитесь, что IP адрес правильный (проверьте в IP Webcam)
3. ✅ Попробуйте другой порт (8080, 8081, или тот, что показан в приложении)
4. ✅ Проверьте firewall на компьютере
5. ✅ Попробуйте HTTP URL в браузере: `http://192.168.1.100:8080/video`

### Проблема: "Модель не найдена"

**Решение:**
1. Обучьте модель сначала:
```bash
python scripts/train_model.py
```

2. Или используйте предобученную YOLOv8n (будет работать, но не найдет окурки):
   - Система автоматически загрузит `yolov8n.pt` из ultralytics

### Проблема: Низкий FPS (медленная обработка)

**Решение:**
1. Уменьшите разрешение в IP Webcam
2. Уменьшите размер изображения в конфиге:
```yaml
model:
  input_size: 416  # Вместо 640
```

3. Используйте более легкую модель: `yolov8n` (nano) вместо `yolov8s`

### Проблема: Не находит окурки

**Причины:**
1. ❌ Модель не обучена на окурках → нужно обучить
2. ❌ Окурки слишком маленькие на видео → уменьшите расстояние до объекта
3. ❌ Плохое освещение → улучшите освещение
4. ❌ Низкая уверенность → уменьшите порог в конфиге:
```yaml
model:
  confidence_threshold: 0.3  # Вместо 0.5
```

## 🚀 Интеграция с Обелиском

Для полной работы системы (с отправкой детекций в Обелиск):

1. **Запустите MQTT брокер:**
```bash
docker-compose up -d mosquitto
```

2. **Запустите Обелиск:**
```bash
python -m obelisk.api.main
```

3. **Запустите детектор:**
```bash
python scripts/test_with_webcam.py --ip 192.168.1.100
```

Детекции будут автоматически отправляться в Обелиск через MQTT!

## 💡 Альтернативные источники видео

Если IP Webcam не работает, можно использовать:

1. **Локальная веб-камера:**
```bash
python scripts/test_with_webcam.py --ip 0  # 0 = локальная камера
```

2. **RTSP поток с другого источника:**
```bash
python edge/inference_service/detector.py --source rtsp://user:pass@ip:port/stream
```

3. **Видеофайл:**
```bash
python edge/inference_service/detector.py --source path/to/video.mp4
```
