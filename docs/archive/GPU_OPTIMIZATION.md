# 🚀 Оптимизация GPU до 85% использования

## Обзор

Система теперь автоматически управляет использованием GPU, ограничивая его до 85% максимума, чтобы оставить ресурсы для тестов и других процессов.

## Компоненты оптимизации

### 1. GPU Manager (`obelisk/core/gpu_manager.py`)

**GPUResourceManager** - центральный менеджер ресурсов GPU:

- **Ограничение использования**: Максимум 85% памяти GPU
- **Автоматическая очистка**: Очищает кэш при превышении лимита
- **Оптимальные параметры**: Автоматически вычисляет оптимальный batch size и input size
- **Мониторинг**: Отслеживает использование памяти, температуру, утилизацию

**GPUMemoryManager** - управление памятью GPU:

- Устанавливает лимит памяти через `torch.cuda.set_per_process_memory_fraction(0.85)`
- Проверяет использование каждую секунду
- Автоматически очищает кэш при превышении лимита
- Резервирует память для планирования операций

### 2. Интеграция в ModelEngine

ModelEngine теперь:
- Инициализирует GPU Manager при загрузке моделей
- Использует оптимальный batch size из GPU Manager
- Проверяет память перед каждой детекцией
- Автоматически очищает память при необходимости

### 3. Интеграция в UnifiedEngine

UnifiedEngine теперь:
- Ограничивает количество воркеров до 85% CPU
- Оптимизирует размер очереди на основе доступных ресурсов
- Проверяет GPU память перед обработкой каждого кадра
- Предоставляет статистику GPU в `get_statistics()`

## Оптимальные параметры

### Автоматический расчет batch size:

- **≥6 GB доступно**: batch_size = 8, input_size = 640
- **≥4 GB доступно**: batch_size = 4, input_size = 640
- **≥2 GB доступно**: batch_size = 2, input_size = 416
- **<2 GB доступно**: batch_size = 1, input_size = 416

### Автоматический расчет воркеров:

- **CPU**: 85% от доступных ядер (минимум 1, максимум 6)
- **Очередь**: 5x от количества воркеров (максимум 50)

## Использование

### Автоматическое управление

Система автоматически управляет GPU без дополнительной настройки:

```python
# UnifiedEngine автоматически инициализирует GPU Manager
engine = UnifiedEngine(config)
await engine.initialize()

# GPU Manager автоматически:
# - Устанавливает лимит памяти (85%)
# - Проверяет использование каждую секунду
# - Очищает кэш при необходимости
# - Вычисляет оптимальные параметры
```

### Мониторинг GPU

Статистика GPU доступна через `get_statistics()`:

```python
stats = engine.get_statistics()
gpu_stats = stats.get("gpu", {})

print(f"Использование GPU: {gpu_stats.get('usage_percent', 0):.1f}%")
print(f"Свободно памяти: {gpu_stats.get('free_memory_gb', 0):.2f} GB")
print(f"Оптимальный batch size: {gpu_stats.get('optimal_batch_size', 1)}")
```

### Ручная очистка памяти

```python
# Принудительная очистка памяти GPU
if engine.gpu_manager:
    engine.gpu_manager.cleanup()
```

### Оптимизация производительности

```python
# Полная оптимизация системы (включая GPU)
await engine.optimize_performance()
```

## Ресурсы для тестов

Система оставляет 15% ресурсов для тестов:

- **GPU**: Максимум 85% памяти (15% запас)
- **CPU**: Максимум 85% ядер (15% запас)
- **Память**: Автоматическая очистка при необходимости

## Преимущества

1. **Стабильность**: Система не перегружает GPU
2. **Производительность**: Оптимальные параметры для каждого GPU
3. **Масштабируемость**: Автоматическая адаптация к доступным ресурсам
4. **Тестирование**: Ресурсы всегда доступны для тестов
5. **Мониторинг**: Полная статистика использования GPU

## Конфигурация

### Настройка лимита использования GPU

```yaml
# config/config.yaml
model_engine:
  device: cuda:0
  max_gpu_usage_percent: 0.85  # 85% максимум (по умолчанию)
  half_precision: true  # FP16 для ускорения
```

### Настройка количества воркеров

```yaml
performance:
  max_workers_percent: 0.85  # 85% от доступных ядер
```

## Тесты

Тесты автоматически получают ресурсы:

1. **GPU память**: 15% всегда доступно для тестов
2. **CPU**: 15% ядер всегда доступно для тестов
3. **Автоматическая очистка**: GPU очищается перед тестами при необходимости

### Запуск тестов

```bash
# Тесты автоматически получат ресурсы
pytest tests/ -v

# С проверкой GPU статистики
pytest tests/ -v --gpu-stats
```
