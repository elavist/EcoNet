## 📋 Методы

### Новые методы:
- `import_media_file()` - импорт файла
- `load_media_file(file_id)` - загрузка из списка
- `refresh_media_list()` - обновление списка
- `delete_media_file(file_id)` - удаление файла
- `_toggle_detection_filter()` - переключение фильтра

### Обновленные методы:
- `load_video()` - теперь перенаправляет на импорт
- `_on_video_frame()` - проверяет фильтр детекции
- `_process_frame_async()` - улучшенное логирование

## 📚 Использование

1. **Импорт файла:** Кнопка "➕ Импорт" → выбор файла → автоматическое копирование
2. **Загрузка в плеер:** Клик по файлу в списке
3. **Запуск воспроизведения:** Кнопка "▶️ Старт"
4. **Фильтр детекции:** Чекбокс "🔍 Детекция"
5. **Удаление файла:** Кнопка "🗑️" в списке
