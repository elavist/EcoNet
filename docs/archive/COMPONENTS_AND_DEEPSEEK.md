# Компоненты ЭкоНет и использование DeepSeek

## 🧠 DeepSeek - Мозг ЭкоНет

### Где используется:
- **Конфигурация**: `config/config.yaml`
  ```yaml
  chat:
    llm_provider: "ollama"
    llm_model: "deepseek-v3.1:671b-cloud"
  ```

### Как работает:
1. **Ollama** - локальный сервер LLM (http://localhost:11434)
2. **DeepSeek v3.1** - модель для генерации ответов
3. **LLM Integration** (`obelisk/services/llm_integration.py`) - обертка для работы с Ollama
4. **ChatService** (`obelisk/services/chat_service.py`) - использует LLM для умных ответов

### Поток данных:
```
Пользователь → ChatService → LLM Integration → Ollama API → DeepSeek → Ответ
```

## 🧩 Компоненты системы

### 1. **SelfIdentityService** (Самоидентификация)
- **Файл**: `obelisk/services/self_identity.py`
- **Назначение**: ЭкоНет понимает свою структуру, код, компоненты
- **Использование**:
  - Сканирует кодовую базу при запуске
  - Анализирует файлы, классы, функции
  - Ведет память и мысли
  - Отвечает на вопросы о себе

### 2. **SelfModificationService** (Самомодификация)
- **Файл**: `obelisk/services/self_modification.py`
- **Назначение**: ЭкоНет может изменять свой код
- **Использование**:
  - Создает резервные копии перед изменениями
  - Модифицирует файлы проекта
  - Проверяет синтаксис
  - Восстанавливает при ошибках

### 3. **SelfLearningService** (Самообучение)
- **Файл**: `obelisk/services/self_learning.py`
- **Назначение**: ЭкоНет учится и самосовершенствуется
- **Использование**:
  - Отслеживает метрики производительности
  - Анализирует тренды
  - Генерирует идеи улучшения
  - Применяет улучшения автоматически

### 4. **ChatService** (Диалог)
- **Файл**: `obelisk/services/chat_service.py`
- **Назначение**: Обработка сообщений и генерация ответов
- **Использование**:
  - Классифицирует намерения пользователя
  - Использует DeepSeek через LLM Integration
  - Интегрирует все компоненты
  - Управляет историей диалога

### 5. **VisionContext** (Визуальный контекст)
- **Файл**: `obelisk/services/vision_context.py`
- **Назначение**: Анализ того, что видит ЭкоНет
- **Использование**:
  - Анализирует кадры видео
  - Предоставляет контекст для ответов
  - Интегрируется с детектором

### 6. **ActiveLearner** (Активное обучение)
- **Файл**: `obelisk/services/active_learner.py`
- **Назначение**: Автоматическое обучение на новых примерах
- **Использование**:
  - Собирает неопределенные кадры
  - Автоматически размечает данные
  - Запускает дообучение модели
  - Деплоит улучшенные модели

### 7. **CigaretteDetector** (Детектор)
- **Файл**: `edge/inference_service/detector.py`
- **Назначение**: Детекция окурков в реальном времени
- **Использование**:
  - Загружает YOLO модель
  - Обрабатывает кадры видео
  - Возвращает детекции с координатами

## 🔄 Интеграция компонентов

### При запуске:
1. **SelfIdentityService** сканирует кодовую базу
2. **SelfModificationService** инициализируется с SelfIdentity
3. **SelfLearningService** инициализируется с обоими
4. **ChatService** получает все три сервиса
5. **DeepSeek** подключается через Ollama

### При общении:
1. Пользователь отправляет сообщение
2. **ChatService** классифицирует намерение
3. Если нужен LLM → **LLM Integration** → **Ollama** → **DeepSeek**
4. Ответ обогащается контекстом из **SelfIdentity**
5. **SelfLearning** записывает опыт

### При детекции:
1. **CigaretteDetector** обрабатывает кадр
2. **VisionContext** анализирует детекции
3. **ActiveLearner** собирает неопределенные кадры
4. **ChatService** может ответить о том, что видит

## 🎯 Использование DeepSeek

DeepSeek используется для:
- Генерации умных ответов на вопросы
- Понимания контекста диалога
- Анализа визуального контекста
- Помощи в самосовершенствовании

Без DeepSeek система работает в "простом режиме" с правилами и шаблонами.
