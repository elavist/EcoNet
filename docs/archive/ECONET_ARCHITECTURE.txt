╔══════════════════════════════════════════════════════════════════════╗
║                        КЛЮЧЕВЫЕ ВЗАИМОДЕЙСТВИЯ                       ║
╚══════════════════════════════════════════════════════════════════════╝

   1. ЭкоНет → DeepSeek
      Когда: Пользователь отправляет сообщение
      Что: ChatService вызывает LLM Engine
      Контекст: Включает детекции YOLO, визуальный анализ

   2. ЭкоНет → YOLO
      Когда: Обработка каждого кадра видео
      Что: ModelEngine выполняет детекцию окурков
      Результат: Детекции с координатами

   3. YOLO → DeepSeek
      Когда: DeepSeek нужен визуальный контекст
      Что: Детекции YOLO → VisionContext → ChatService → DeepSeek


═══════════════════════════════════════════════════════════════════════

   РЕЗЮМЕ:
   
   ЭКОНЕТ - главный координатор автономной системы роя для очистки от мусора
     ├─ DEEPSEEK - мозг (понимание, рассуждение, принятие решений)
     ├─ YOLO - глаза (детекция мусора и окурков)
     ├─ Coordinator - координатор (управление роем роботов)
     ├─ Information Hub - синхронизация (центральный узел)
     ├─ ChatService - интегратор (объединяет DeepSeek + YOLO)
     ├─ NeuralSync - нейронная сеть для связи компонентов
     └─ Рой Роботов - автономные роботы-сборщики (через MQTT)
     
   УЛУЧШЕННАЯ МАТЕМАТИКА:
     ├─ IoU группировка детекций (Intersection over Union)
     ├─ Динамические веса моделей (на основе исторической производительности)
     ├─ Комбинированное взвешивание (вес модели × уверенность детекции)
     └─ Многокритериальная оптимизация выбора робота (расстояние, батарея, загрузка, эффективность)
