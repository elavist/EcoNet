# ✅ Оптимизация для 60+ FPS на Windows 11

## 🎯 Цель

Достичь стабильных **60+ FPS** на Windows 11 при обработке видео с детекцией.

## 📊 Выполненные Оптимизации

### 1. ✅ Конфигурация (config.yaml)

**Изменения:**
- `input_size: 320` (было 416) - уменьшен размер входного изображения для YOLO
- `confidence_threshold: 0.6` (было 0.5) - увеличен для уменьшения детекций
- `max_detections: 50` (было 100) - уменьшен для ускорения
- `frame_skip: 2` (было 0) - обрабатывать каждый 3-й кадр (0, 3, 6, 9...)
- `parallel_vision: false` (было true) - отключен VisionContext (не нужен без чата)
- `max_cache_size: 100` (было 50) - увеличен для лучшего кэширования
- `display_update_interval: 2` - обновлять отображение каждый 2-й кадр

### 2. ✅ ModelEngine (model_engine.py)

**Оптимизации:**
- Автоматическое уменьшение `input_size` до 320 для CPU
- Убрано избыточное логирование (INFO → DEBUG)
- Оптимизированы параметры YOLO для скорости

**Было:**
```python
input_size = 416  # Для CPU
logger.info(...)  # Много логирования
```

**Стало:**
```python
input_size = min(input_size, 320)  # Максимум 320 для CPU
logger.debug(...)  # Только debug логирование
```

### 3. ✅ UnifiedEngine (unified_engine.py)

**Оптимизации:**
- Уменьшен таймаут с 15ms до 10ms для гарантии 60+ FPS
- Убрано избыточное логирование
- Оптимизирован пропуск кадров через `frame_skip`

**Было:**
```python
timeout=0.015  # 15ms
logger.info(...)  # Много логирования
```

**Стало:**
```python
timeout=0.010  # 10ms для 60+ FPS
logger.debug(...)  # Только debug логирование
```

### 4. ✅ GUI (gui_material.py)

**Оптимизации:**
- Уменьшение размера кадра перед обработкой (макс 640px)
- Оптимизация отображения (обновление не каждый кадр)
- Убрано избыточное логирование

**Новое:**
```python
# Уменьшаем размер кадра перед обработкой
max_size = 640
if frame_w > max_size or frame_h > max_size:
    scale = min(max_size / frame_w, max_size / frame_h)
    frame_for_processing = cv2.resize(frame_copy, (new_w, new_h))

# Обновляем отображение с интервалом
display_interval = 2  # Каждый 2-й кадр
if self._display_frame_counter % display_interval == 0:
    self.display_frame(frame)
```

## 🔧 Дополнительные Рекомендации

### Для еще большего ускорения:

1. **GPU ускорение:**
   - Убедитесь что CUDA установлен
   - Измените `device: cuda` в config.yaml
   - Можно увеличить `input_size` до 416 для GPU

2. **Дальнейшее уменьшение размера:**
   - Можно уменьшить `input_size` до 256 для еще большего ускорения
   - Но точность может снизиться

3. **Увеличение frame_skip:**
   - Можно установить `frame_skip: 4` (каждый 5-й кадр)
   - Это даст еще больше FPS, но детекции будут реже

4. **Отключение VisionContext:**
   - Уже отключен (`parallel_vision: false`)
   - Это экономит ресурсы
