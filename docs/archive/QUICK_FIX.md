# 🔧 Быстрое решение проблемы "модель не видит окурки"

## Проблема
После перезапуска модель не находит окурки на видео с IP Webcam, хотя раньше работала.

## ✅ Решение

### 1. Проверьте модель
```powershell
python scripts\test_model_load.py
```
Должно показать, что модель работает.

### 2. Запустите тест с **пониженным порогом уверенности**

Порог по умолчанию (0.5) может быть слишком высоким для видео. Попробуйте:

```powershell
python scripts\test_with_webcam.py --ip 192.168.1.XXX --conf 0.3
```

Замените `192.168.1.XXX` на IP вашего телефона.

**Пороги для тестирования:**
- `--conf 0.3` - более чувствительная детекция (рекомендуется для начала)
- `--conf 0.4` - средний порог
- `--conf 0.5` - стандартный (из конфига)

### 3. Проверьте логи

При запуске вы увидите:
```
Порог уверенности: 0.3
Размер входного изображения: 640
✅ Подключение к IP Webcam успешно
```

Если находятся детекции, вы увидите:
```
Кадр 123: найдено 1 детекций
  - cig_butt: уверенность 0.756
```

### 4. Если все еще не работает

**Проверьте:**
1. ✅ Модель загружается? (`python scripts\test_model_load.py`)
2. ✅ IP Webcam подключен? (проверьте в браузере: `http://IP:8080/video`)
3. ✅ Окурки достаточно крупные на видео? (поднесите камеру ближе)
4. ✅ Хорошее освещение?

**Попробуйте:**
- Еще более низкий порог: `--conf 0.2`
- Локальную камеру: `python scripts\test_with_webcam.py --ip 0 --conf 0.3`
- Тестовое изображение из датасета (должно работать)

## 📝 Команды для копирования

```powershell
# 1. Тест модели
python scripts\test_model_load.py

# 2. Тест с IP Webcam (низкий порог)
python scripts\test_with_webcam.py --ip 192.168.1.XXX --conf 0.3

# 3. Если не работает - попробуйте еще ниже
python scripts\test_with_webcam.py --ip 192.168.1.XXX --conf 0.2
```

## 💡 Почему это работает?

- Видео с IP Webcam может иметь другое качество/разрешение чем тренировочные данные
- Освещение и угол съемки могут отличаться
- Понижение порога позволяет находить объекты с меньшей уверенностью, но все еще надежно
