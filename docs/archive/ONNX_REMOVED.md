# ✅ ONNX УДАЛЕН - ТОЛЬКО PT МОДЕЛИ

## 🚫 Проблема с ONNX

Вы сказали: **"ONNX не дообрабатывает кадр"**

Это известная проблема ONNX:
- ❌ Конвертация из PT теряет точность
- ❌ Неполная обработка кадров
- ❌ Медленнее на GPU чем PT
- ❌ Фиксированный размер входа

## ✅ Решение: Только PT модели

### Что изменено:

1. **ModelEngine** (`obelisk/core/model_engine.py`)
   - ✅ ONNX полностью отключен
   - ✅ Только PT модели загружаются
   - ✅ Если PT не найдена - ошибка (не fallback на ONNX)

2. **Edge Detector** (`edge/inference_service/detector.py`)
   - ✅ Приоритет PT модели
   - ✅ ONNX больше не загружается

3. **Config** (`config/config.yaml`)
   - ✅ Добавлен флаг `use_onnx: false`
   - ✅ Модель указана как `.pt`

## 📊 Что такое ONNX?

**ONNX (Open Neural Network Exchange)** - формат для обмена моделями между фреймворками.

### Проблемы:
1. ❌ **Теряет точность** при конвертации
2. ❌ **Не дообрабатывает кадры** - ваша проблема!
3. ❌ **Медленнее на GPU** чем PT с CUDA
4. ❌ **Фиксированный размер** (416) - ограничивает

## 🔍 Есть ли аналоги лучше?

### Для GPU (CUDA):
- ✅ **PT (PyTorch)** - ЛУЧШИЙ выбор! ✅ (используем)
- ⚠️ ONNX Runtime - медленнее и менее точный
- ❌ TensorFlow - не используется в проекте

### Вывод:
**PT модель на GPU с CUDA** - это ЛУЧШИЙ выбор для ЭКОНЕТ!
