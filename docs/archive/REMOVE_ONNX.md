# ✅ ONNX ОТКЛЮЧЕН - ТОЛЬКО PT МОДЕЛИ

## 🚫 Почему ONNX отключен

### Проблемы ONNX:
1. ❌ **Не дообрабатывает кадры** - ваша проблема!
2. ❌ **Теряет точность** при конвертации из PT
3. ❌ **Медленнее на GPU** чем PT с CUDA
4. ❌ **Фиксированный размер** входа (416) - ограничивает гибкость
5. ❌ **Меньше оптимизаций** для GPU

## ✅ Решение: Только PT модели

### Преимущества PT:
1. ✅ **Максимальная точность** - прямая работа с обученной моделью
2. ✅ **Полная обработка кадров** - все кадры обрабатываются правильно
3. ✅ **Быстрее на GPU** - нативный PyTorch + CUDA
4. ✅ **Гибкость** - любой размер входа (320, 416, 640, 832)
5. ✅ **FP16 поддержка** - отлично работает
6. ✅ **Batch processing** - оптимизирован для GPU

## 🔧 Что изменено

### 1. ModelEngine (`obelisk/core/model_engine.py`)
- ✅ ONNX полностью отключен
- ✅ Только PT модели загружаются
- ✅ Если PT модель не найдена - ошибка (не fallback на ONNX)

### 2. Edge Detector (`edge/inference_service/detector.py`)
- ✅ Приоритет PT модели
- ✅ ONNX больше не загружается

## 📝 Аналоги лучше ONNX?

### Для GPU (CUDA):
- ✅ **PT (PyTorch)** - лучший выбор! ✅ (используем)
- ⚠️ ONNX Runtime - медленнее и менее точный
- ❌ TensorFlow - не используется в проекте

### Для CPU:
- ✅ **PT (PyTorch)** - все равно лучше
- ⚠️ ONNX Runtime - может быть быстрее на старых CPU
- ❌ TensorFlow - не используется

**Вывод**: PT модель на GPU - это ЛУЧШИЙ выбор! ✅
