# ⚡ Быстрый тест системы с IP Webcam

## 🎯 Вариант 1: Тест БЕЗ обучения (сразу можно проверить работу)

Модель **НЕ обучена** на окурках, но можно проверить работу системы:

### Шаг 1: Запустите IP Webcam на телефоне

1. Откройте приложение **IP Webcam**
2. Нажмите **"Start server"**
3. Запишите IP адрес (например: `192.168.1.100:8080`)

### Шаг 2: Запустите тест

```bash
python scripts/test_with_webcam.py --ip 192.168.1.100
```

**Замените `192.168.1.100` на IP вашего телефона!**

### Что вы увидите:
- ✅ Видео с камеры телефона в реальном времени
- ⚠️ Детекция может не находить окурки (модель не обучена)
- ✅ Но вы увидите, что система работает!

## 🎓 Вариант 2: Тест С обучением (рекомендуется для реальной детекции)

Для **реальной детекции окурков** сначала обучите модель:

### Шаг 1: Настройте датасет

```bash
python scripts/setup_dataset.py
```

Это интегрирует ваш существующий датасет `Cigarette Butt Detector.v5i.yolov8` в систему.

### Шаг 2: Быстрое обучение (для теста)

Для быстрого теста обучите на небольшое количество эпох:

```bash
# Создайте быстрый скрипт или измените train_model.py
cd models/cigarette_detector
python -c "
from ultralytics import YOLO
model = YOLO('yolov8n.pt')
model.train(data='../../datasets/cigarette_butt/data.yaml', epochs=10, imgsz=640, batch=16)
"
```

Это займет ~10-15 минут на CPU.

### Шаг 3: Полное обучение (лучший результат)

```bash
python scripts/train_model.py
```

Это займет:
- **CPU:** 2-4 часа
- **GPU:** 20-30 минут

### Шаг 4: Тестирование

После обучения:

```bash
python scripts/test_with_webcam.py --ip 192.168.1.100
```

Теперь система **реально найдет окурки**! 🎉

## 🔧 Решение проблем

### ❌ "Не удалось подключиться к IP Webcam"

**Решения:**
1. ✅ Убедитесь, что телефон и компьютер в **одной Wi-Fi сети**
2. ✅ Проверьте IP адрес в приложении IP Webcam
3. ✅ Проверьте firewall на компьютере
4. ✅ Попробуйте открыть в браузере: `http://192.168.1.100:8080/video`

### ❌ "Модель не найдена"

**Решение:**
- Используйте Вариант 1 (тест без обучения) - система автоматически загрузит предобученную YOLOv8n
- Или обучите модель по Варианту 2

### ❌ Не находит окурки

**Причины:**
1. Модель не обучена → обучите по Варианту 2
2. Окурки слишком маленькие → поднесите камеру ближе
3. Плохое освещение → улучшите освещение
