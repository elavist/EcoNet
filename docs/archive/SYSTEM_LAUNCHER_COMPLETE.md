## Использование

### Запуск системы

**Вариант 1: Python скрипт**
```bash
python scripts/start_econet_system.py
```

**Вариант 2: Windows батник**
```bash
ЗАПУСТИТЬ_ЭКОНЕТ.bat
```

**Вариант 3: Вручную**
```bash
# 1. Запуск MQTT брокера (если нужно)
docker-compose up -d mosquitto

# 2. Запуск Обелиска
python -m obelisk.api.main
```

## Что делает скрипт запуска

1. **Проверка MQTT брокера**
   - Проверяет доступность на localhost:1883
   - Если недоступен, пытается запустить через Docker

2. **Запуск Обелиска**
   - Запускает FastAPI сервер
   - Показывает PID процесса
   - Выводит URL для доступа

3. **Ожидание готовности**
   - Ждет до 30 секунд
   - Проверяет health endpoint
   - Показывает статус всех сервисов

4. **Проверка системы**
   - Проверяет все основные endpoints
   - Показывает статус здоровья
   - Выводит итоговый отчет

5. **Корректное завершение**
   - Останавливает все процессы при Ctrl+C
   - Освобождает ресурсы
