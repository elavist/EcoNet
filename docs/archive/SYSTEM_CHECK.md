## 📊 Ожидаемая производительность

### На CPU:
- Без оптимизации: 10-20 FPS
- С оптимизацией: 30-45 FPS
- С пропуском кадров: 50-60 FPS

### На GPU (CUDA):
- Без оптимизации: 40-60 FPS
- С FP16: 60-100+ FPS ⭐

### На Apple Silicon (MPS):
- С оптимизацией: 50-80 FPS

## 🔧 Настройка для максимальной производительности

Если у вас есть GPU, измените в `config/config.yaml`:
```yaml
edge:
  device: cuda:0  # Вместо cpu
```

Система автоматически:
- Определит доступность GPU
- Включит FP16 ускорение
- Оптимизирует обработку
