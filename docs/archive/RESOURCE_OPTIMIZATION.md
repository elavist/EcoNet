# ✅ Оптимизация Потребления Ресурсов ПК

## 🎯 Цель

Оптимизировать потребление ресурсов ПК (CPU, RAM, GPU) для лучшей и более четкой обработки видео, сохраняя качество детекции.

## 📊 Выполненные Оптимизации

### 1. ✅ Конфигурация (config.yaml)

**Изменения:**
- `input_size: 416` - оптимальный баланс качества и скорости (не слишком маленький)
- `confidence_threshold: 0.5` - стандартное значение для качества
- `max_detections: 100` - достаточное количество для качественной детекции
- `frame_skip: 1` - обрабатывать каждый 2-й кадр (баланс качества и скорости)
- `max_frame_size: 1280` - максимальный размер кадра для обработки (сохраняет качество)

### 2. ✅ ModelEngine (model_engine.py)

**Оптимизации:**
- `input_size: 416` для CPU (оптимальный баланс)
- Добавлены параметры для качества: `agnostic_nms: False`, `retina_masks: False`
- Сохранено качество детекции

### 3. ✅ UnifiedEngine (unified_engine.py)

**Оптимизации:**
- Количество воркеров: `min(cpu_count, 6)` - не перегружаем систему
- Размер очереди: `20` - оптимальный для Windows 11
- Таймаут: `20ms` - баланс качества и скорости
- `frame_skip: 1` - каждый 2-й кадр

### 4. ✅ GUI (gui_material.py)

**Оптимизации:**
- Умное уменьшение размера кадра (только если очень большой)
- Использование `INTER_AREA` для качественного уменьшения
- Сохранение оригинального размера для нормальных кадров
- Убрано избыточное логирование

**Логика:**
```python
# Уменьшаем только если кадр очень большой (экономия ресурсов)
if frame_w > max_size or frame_h > max_size:
    # Используем качественную интерполяцию для сохранения четкости
    frame_for_processing = cv2.resize(..., interpolation=cv2.INTER_AREA)
else:
    # Используем оригинальный размер для лучшего качества
    frame_for_processing = frame_copy.copy()
```

## 🔧 Оптимизация Ресурсов

### CPU
- Количество воркеров ограничено количеством ядер CPU

### RAM
- Размер очереди: 20 кадров (оптимально)
- Кэш: 50 записей (не перегружаем память)
- Умное уменьшение больших кадров

- FP16 precision для ускорения
- Оптимальные параметры YOLO
