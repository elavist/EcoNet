# ✅ Автоматическая Обработка Видео и Тестирование Модели

## 🎯 Реализовано

### 1. Проверка модели при запуске

После инициализации `UnifiedEngine` автоматически выполняется проверка готовности модели:
- Проверка наличия загруженных моделей
- Проверка устройства (CPU/GPU)
- Тестовая обработка кадра для проверки работоспособности
- Подробные логи ошибок при проблемах

**Результаты проверки:**
- ✅ Модель загружена: количество моделей, устройство
- ✅ Тестовый кадр обработан успешно
- ❌ Ошибки с подробным описанием

### 2. Автоматическая обработка видео

После успешной проверки модели автоматически запускается обработка всех непроработанных видео:

**Логика:**
1. Проверка модели (должна пройти успешно)
2. Поиск всех видео с `processed: false` и `processing_status != "processing"`
3. Автоматический запуск предобработки для каждого видео
4. Сохранение детекций в файлы
5. Обновление статуса в UI

**Преимущества:**
- ✅ Видео обрабатываются автоматически при запуске
- ✅ Не нужно вручную запускать обработку
- ✅ Все новые видео будут обработаны при следующем запуске

### 3. Система тестирования модели

Создан модуль `obelisk/core/model_testing.py` для тестирования модели с разными параметрами:

**Методы:**

#### `test_model_readiness()`
Базовая проверка готовности модели:
- Проверка наличия моделей
- Проверка устройства
- Тестовая обработка кадра
- Возвращает детальный результат проверки

#### `test_different_confidence_levels(test_video_path, confidence_levels)`
Тестирование с разными уровнями точности (confidence threshold):
- Тестирует модель с разными значениями confidence (по умолчанию: 0.3, 0.5, 0.7)
- Обрабатывает несколько кадров из тестового видео
- Собирает статистику для каждого уровня:
  - Количество обработанных кадров
  - Общее количество детекций
  - Средняя уверенность
  - Максимальная/минимальная уверенность
  - Количество детекций на кадр

**Пример использования:**
```python
from obelisk.core.model_testing import ModelTester

tester = ModelTester(unified_engine)

# Проверка модели
readiness = await tester.test_model_readiness()
if readiness["test_passed"]:
    print(f"Модель готова: {readiness['models_count']} модель(ей)")

# Тестирование с разными confidence
results = await tester.test_different_confidence_levels(
    "path/to/test_video.mp4",
    confidence_levels=[0.3, 0.5, 0.7]
)
```

## 🔄 Рабочий процесс

### При запуске программы:

1. **Инициализация UnifiedEngine**
   ```
   UnifiedEngine → initialize()
   ```

2. **Проверка модели (ModelTester)**
   ```
   test_model_readiness() → проверка загруженных моделей, устройства, тестовый кадр
   ```

3. **Автоматическая обработка видео**
   ```
   _auto_process_videos() → поиск непроработанных видео → предобработка каждого
   ```

4. **Готово к использованию**
   - Модель проверена и готова
   - Все видео обработаны (или в процессе обработки)
   - Можно воспроизводить результаты
