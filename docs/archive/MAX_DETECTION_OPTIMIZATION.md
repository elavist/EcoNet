# ✅ Оптимизация для Максимального Количества Детекций

## 🎯 Цель
Увеличить количество детекций до максимально возможного уровня, затем применить трекинг для отслеживания.

## 📊 Измененные Параметры

### `config/config.yaml`:

#### Модель (model):
```yaml
confidence_threshold: 0.2  # Было: 0.5
  # Минимальный порог для максимального количества детекций
  # Чем ниже порог, тем больше объектов будет обнаружено

input_size: 640  # Было: 416
  # Увеличенный размер для лучшей детализации
  # Больший размер входного изображения = больше детекций

iou_threshold: 0.4  # Было: 0.45
  # Более мягкий порог для меньше фильтрации
  # Меньше агрессивная фильтрация перекрывающихся детекций

max_detections: 300  # Было: 100
  # Максимальное количество детекций на кадр
  # Увеличено в 3 раза для максимального покрытия
```

## 🔄 Логика Обработки

### Порядок обработки видео (предобработка):

```
1. ДЕТЕКЦИЯ (максимальная):
   ├─ confidence_threshold: 0.2 (низкий порог)
   ├─ input_size: 640 (большой размер)
   ├─ max_detections: 300 (максимум детекций)
   └─ Результат: ВСЕ возможные объекты детектируются

2. ТРЕКИНГ (после детекции):
   ├─ IoU threshold: 0.86 (86% совпадение)
   ├─ Применяется К ВСЕМ детекциям
   ├─ Добавляет track_id к детекциям
   └─ НЕ удаляет детекции (только группирует и отслеживает)

3. СОХРАНЕНИЕ:
   ├─ Все детекции с track_id сохраняются
   └─ Используются при воспроизведении
```

## 📈 Ожидаемые Результаты

### Увеличение количества детекций:

| Параметр | До | После | Увеличение |
|----------|-----|-------|------------|
| **confidence_threshold** | 0.5 | 0.2 | ↓ 60% (больше детекций) |
| **input_size** | 416 | 640 | ↑ 54% (лучшая детализация) |
| **max_detections** | 100 | 300 | ↑ 200% (в 3 раза больше) |
| **iou_threshold** | 0.45 | 0.4 | ↓ 11% (меньше фильтрации) |

### Ожидаемое увеличение:
- **В 3-5 раз больше детекций** на кадр
- **Лучшая детализация** благодаря увеличенному input_size
- **Больше покрытие** объектов благодаря низкому confidence

## ⚙️ Технические Детали

### Детекция (ModelEngine):
```python
inference_kwargs = {
    "imgsz": 640,           # Увеличенный размер
    "conf": 0.2,            # Низкий порог
    "iou": 0.4,             # Мягкая фильтрация
    "max_det": 300,         # Максимум детекций
}
```

### Трекинг (ObjectTracker):
```python
tracker = ObjectTracker(
    iou_threshold=0.86,     # Высокий порог для трекинга
    max_missed_frames=5     # Максимум пропущенных кадров
)
# Применяется ПОСЛЕ детекции
tracked_detections = tracker.update(detections, frame_number)
```

## 🔍 Логирование

### Добавлено логирование для контроля:

```python
logger.debug(f"📊 Кадр {frame_number}: получено {len(detections)} детекций (до трекинга)")
logger.debug(f"✅ Кадр {frame_number}: после трекинга - {len(tracked_detections)} детекций с track_id")

```

## ✅ Проверка

1. **Детекции увеличились?** 
   - Проверить логи: "получено X детекций (до трекинга)"
   - Сравнить с предыдущими результатами

2. **Трекинг работает?**
   - Проверить логи: "после трекинга - X детекций с track_id"
   - Все детекции должны иметь track_id

3. **Качество детекций?**
   - Визуально проверить отображение
   - Убедиться, что детекции точны (не ложные срабатывания)

## 🚀 Следующие Шаги

Если детекций все еще мало:
1. Еще больше понизить `confidence_threshold` (до 0.1)
2. Увеличить `input_size` (до 800 или 1024)
3. Увеличить `max_detections` (до 500)

Если слишком много ложных срабатываний:
1. Повысить `confidence_threshold` (до 0.25)
2. Увеличить `iou_threshold` (до 0.45)
3. Настроить трекинг для фильтрации дубликатов

## 📝 Примечания

- Трекинг **не уменьшает** количество детекций, только добавляет track_id
- Все детекции сохраняются с track_id
- При воспроизведении используются сохраненные детекции
- Трекинг работает только при предобработке видео (не в реальном времени)

**Система настроена на максимальное количество детекций!** ✅
