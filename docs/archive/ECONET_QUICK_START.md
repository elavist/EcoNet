# 🚀 ЭкоНет - Быстрый старт

## ЭкоНет теперь "ожил"! 🎉

Система теперь может:
- ✅ **Видеть** и понимать что происходит в кадре
- ✅ **Отвечать** на ваши вопросы
- ✅ **Учиться** через диалог
- ✅ **Общаться** через CLI или веб-интерфейс

---

## ⚡ Быстрый запуск (3 шага)

### 1. Запустите интерактивный диалог

```powershell
python scripts\chat_with_econet.py
```

### 2. Запустите детекцию (в диалоге)

```
Вы: start 0
```

Или с IP Webcam:
```
Вы: start http://192.168.1.XXX:8080/video
```

### 3. Задавайте вопросы!

```
Вы: Что видишь?
ЭкоНет: Я вижу 3 окурков...

Вы: Сколько окурков?
ЭкоНет: Я вижу 3 окурка. Средняя уверенность: 85.9%.

Вы: Это окурок
ЭкоНет: Спасибо! Запомнил этот пример...
```

---

## 🌐 Веб-интерфейс

### Запуск сервера:

```powershell
python obelisk\api\main.py
```

### Откройте в браузере:

```
http://localhost:8000/chat
```

Красивый веб-интерфейс для общения с ЭкоНет!

---

## 💡 Примеры использования

### Вопросы о видении

- "Что видишь?" - Что видит система сейчас
- "Сколько окурков?" - Количество обнаруженных окурков
- "Где окурки?" - Расположение окурков в кадре

### Обучение

- "Это окурок" - Положительная обратная связь
- "Это не окурок" - Отрицательная обратная связь

### Команды

- "Найди окурки" - Запустить поиск
- "Убери окурки" - Создать задачу для робота
- "Статус" - Статус системы
