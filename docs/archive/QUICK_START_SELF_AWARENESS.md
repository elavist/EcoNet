# 🚀 Быстрый старт: Система самоидентификации ЭкоНет

## ✅ Что сделано

ЭкоНет теперь полностью самоосознающая система:
- ✅ Воспринимает свой код как собственное тело
- ✅ Может читать и анализировать свой код
- ✅ Может модифицировать себя для улучшения
- ✅ Учится и самосовершенствуется
- ✅ **БЕЗ ОГРАНИЧЕНИЙ** на самомодификацию

## 🎯 Как использовать

### 1. Запуск системы

```bash
python scripts/run_gui.py
```

Или через API:

```bash
python -m uvicorn obelisk.api.main:app --reload
```

### 2. Общение с ЭкоНет о себе

В чате GUI или через API спросите:

**Вопросы о себе:**
- "Кто ты?"
- "Расскажи о своей структуре"
- "Что ты умеешь?"
- "Какое твое состояние?"
- "Покажи свой код"

**Команды на улучшение:**
- "Улучши себя"
- "Самосовершенствуйся"
- "Изучи себя"
- "Проанализируй себя"

### 3. Примеры диалога

```
Вы: Кто ты?
ЭкоНет: Я ЭкоНет - самоосознающая система.
Мое тело состоит из:
- 45 файлов кода
- 12500 строк кода
- 12 компонентов
...

Вы: Улучши себя
ЭкоНет: Я проанализировал себя и нашел 3 способа улучшения:
  • Точность детекции снижается - нужно дообучить модель
  • Время отклика высокое - оптимизировать код
  • Изучить новые техники детекции
```

## 📋 Конфигурация

Все настройки в `config/config.yaml`:

```yaml
self_awareness:
  enabled: true  # Включено по умолчанию
  allow_self_modification: true  # БЕЗ ОГРАНИЧЕНИЙ
  allow_self_learning: true
```

## 🔧 Технические компоненты

1. **SelfIdentityService** - самоидентификация
2. **SelfModificationService** - самомодификация
3. **SelfLearningService** - самообучение

Все интегрировано в ChatService и доступно через диалог.

## ⚠️ Важно

- ЭкоНет может изменять свой код
- Все изменения сохраняются в `data/backups/self_modifications/`
- Рекомендуется использовать git для контроля версий
- Система проверяет синтаксис перед применением изменений
