## 🎯 DeepSeek - Мозг ЭкоНет

### Где находится:
```yaml
# config/config.yaml
chat:
  llm_provider: "ollama"
  llm_model: "deepseek-v3.1:671b-cloud"
```

### Как используется:
1. **Ollama** запускается локально (http://localhost:11434)
2. **LLM Integration** (`obelisk/services/llm_integration.py`) подключается к Ollama
3. **ChatService** использует LLM для генерации ответов
4. **DeepSeek** обрабатывает запросы и генерирует умные ответы

## 🧩 Компоненты системы

### Основные сервисы:
1. **SelfIdentityService** - самоидентификация
2. **SelfModificationService** - самомодификация
3. **SelfLearningService** - самообучение
4. **ChatService** - диалог (интегрирует все)
5. **VisionContext** - визуальный анализ
6. **ActiveLearner** - активное обучение
7. **CigaretteDetector** - детекция окурков

### Интеграция:
Все компоненты связаны через ChatService, который:
- Использует DeepSeek для умных ответов
- Интегрирует SelfIdentity для ответов о себе
- Использует VisionContext для анализа видео
- Записывает опыт в SelfLearning
