## 🔍 Логика Определения Модели

1. **Получение пути к модели:**
   ```python
   weights_path = model_config.get("weights_path", "best.pt")
   ```

2. **Извлечение имени файла:**
   ```python
   from pathlib import Path
   model_file = Path(weights_path).name  # best.pt
   ```

3. **Подсчет количества моделей:**
   ```python
   models_list = list(model_engine.models.keys())
   model_count = len(models_list)  # 1 модель
   ```

4. **Получение устройства:**
   ```python
   device = test_results.get('device', 'N/A')  # cpu/cuda
   ```

5. **Формирование строки статуса:**
   ```python
   status_text = f"{model_file} ({model_count} модель) [{device}]"
   ```
