# 🤖 ЭкоНет - Интерактивный диалог

## Что это?

ЭкоНет теперь **"ожил"** - вы можете общаться с системой, задавать вопросы о том, что она видит, и учить её через диалог!

## Возможности

✅ **Визуальное понимание** - система видит и понимает что происходит в кадре  
✅ **Диалог** - задавайте вопросы, получайте ответы  
✅ **Интерактивное обучение** - учите систему через обратную связь  
✅ **Контекстные ответы** - система понимает что видит и отвечает соответственно

## 🚀 Быстрый старт

### Вариант 1: CLI интерфейс (рекомендуется)

```powershell
# Запуск интерактивного диалога
python scripts\chat_with_econet.py

# С автоматическим запуском детекции (IP Webcam)
python scripts\chat_with_econet.py --source http://192.168.1.XXX:8080/video

# С локальной камерой
python scripts\chat_with_econet.py --source 0
```

### Вариант 2: REST API

```powershell
# Запуск сервера
python obelisk\api\main.py

# Отправка сообщения (через curl или Postman)
curl -X POST "http://localhost:8000/api/v1/chat/message" \
  -H "Content-Type: application/json" \
  -d '{"message": "Что видишь?"}'
```

### Вариант 3: WebSocket (для веб-интерфейса)

```javascript
const ws = new WebSocket('ws://localhost:8000/api/v1/chat/ws');
ws.onmessage = (event) => {
  const data = JSON.parse(event.data);
  console.log('ЭкоНет:', data.response);
};
ws.send(JSON.stringify({message: "Привет!"}));
```

## 💬 Примеры диалога

### Вопросы о том, что видит система

```
Вы: Что видишь?
ЭкоНет: Я вижу 3 окурков:
  • Окурок 1: уверенность 87.3%
  • Окурок 2: уверенность 92.1%
  • Окурок 3: уверенность 78.5%

Вы: Сколько окурков?
ЭкоНет: Я вижу 3 окурка. Средняя уверенность: 85.9%.

Вы: Где окурки?
ЭкоНет: Окурки находятся:
Окурок 1: центр (320, 240), уверенность 87.3%
Окурок 2: центр (640, 480), уверенность 92.1%
Окурок 3: центр (160, 120), уверенность 78.5%
```

### Обучение через диалог

```
Вы: Это окурок
ЭкоНет: Спасибо! Запомнил этот пример. Он будет использован для улучшения модели.

Вы: Это не окурок
ЭкоНет: Понял, это ложное срабатывание. Запомню и улучшу модель, чтобы не путать в будущем.
```

### Команды

```
Вы: Найди окурки
ЭкоНет: Ищу окурки... Запускаю детекцию. Пожалуйста, направьте камеру на область поиска.

Вы: Убери окурки
ЭкоНет: Понял! Создаю задачу для робота-сборщика. Как только окурок будет обнаружен, робот начнет сбор.
```

### Статус системы

```
Вы: Статус
ЭкоНет: Я ЭкоНет, система автономной уборки окурков.

📊 Текущий статус:
  • Система: активна
  • Точность модели: 95.61%
  • Производительность: ~40 FPS
  • Детектор: активен
  • Активное обучение: включено
```

## 📋 Команды CLI

### Основные команды

- `start <источник>` - Запустить детекцию
  - `start 0` - Локальная камера
  - `start http://192.168.1.100:8080/video` - IP Webcam
- `stop` - Остановить детекцию
- `status` - Статус системы
- `clear` - Очистить историю диалога
- `help` - Показать помощь
- `quit` / `exit` - Выход

### Примеры вопросов

- "Что видишь?" - Что видит система сейчас
- "Сколько окурков?" - Количество обнаруженных окурков
- "Где окурки?" - Расположение окурков в кадре
- "Это окурок" - Положительная обратная связь для обучения
- "Это не окурок" - Отрицательная обратная связь для обучения

## 🔧 Настройка

### Конфигурация (config/config.yaml)

```yaml
chat:
  enabled: true  # Включить интерактивный диалог
  use_llm: false  # Использовать LLM (OpenAI/Ollama)
  llm_provider: "openai"  # openai, ollama, local
  llm_model: "gpt-4o-mini"
  llm_api_key: null  # Установить через OPENAI_API_KEY
  max_history: 50  # Максимум сообщений в истории
```

### Использование LLM (опционально)

Для более умных ответов можно использовать LLM:

1. **OpenAI** (требует API ключ):
   ```yaml
   chat:
     use_llm: true
     llm_provider: "openai"
     llm_model: "gpt-4o-mini"
     llm_api_key: "sk-..."  # Или через переменную окружения
   ```

2. **Ollama** (локально):
   ```yaml
   chat:
     use_llm: true
     llm_provider: "ollama"
     llm_model: "llama2"  # Или другая модель
   ```
   
   Установка Ollama: https://ollama.ai

## 🎯 Как это работает?

### 1. Визуальный контекст

Система анализирует каждый кадр:
- Количество детекций
- Уверенность детекций
- Расположение объектов
- Качество изображения
- Тип поверхности

### 2. Понимание намерений

Система классифицирует ваши сообщения:
- **Вопросы о видении** - "Что видишь?", "Сколько окурков?"
- **Команды** - "Найди окурки", "Убери окурки"
- **Обучение** - "Это окурок", "Это не окурок"
- **Статус** - "Статус", "Как дела?"

### 3. Генерация ответов

- **Простой режим** (по умолчанию) - правила и шаблоны
- **LLM режим** (опционально) - умные ответы через OpenAI/Ollama

### 4. Интерактивное обучение

Когда вы даёте обратную связь:
- Система запоминает примеры
- Использует их для улучшения модели
- Интегрируется с активным обучением

## 🌐 API Endpoints

### POST `/api/v1/chat/message`

Отправить сообщение ЭкоНет

**Request:**
```json
{
  "message": "Что видишь?",
  "visual_context": {
    "detections": [...],
    "frame_info": {...}
  }
}
```

**Response:**
```json
{
  "response": "Я вижу 3 окурков...",
  "timestamp": "2024-01-20T12:00:00",
  "visual_context": {...}
}
```

### GET `/api/v1/chat/history`

Получить историю диалога

**Response:**
```json
{
  "history": [
    {"role": "user", "content": "...", "timestamp": "..."},
    {"role": "assistant", "content": "...", "timestamp": "..."}
  ]
}
```

### DELETE `/api/v1/chat/history`

Очистить историю диалога

### WebSocket `/api/v1/chat/ws`

Интерактивный диалог через WebSocket

## 🐛 Решение проблем

### "Сервис диалога не инициализирован"

Убедитесь, что в `config/config.yaml`:
```yaml
chat:
  enabled: true
```

### "Не вижу окурков"

1. Проверьте, запущена ли детекция: `start <источник>`
2. Убедитесь, что камера работает
3. Проверьте порог уверенности в конфигурации

### LLM не работает

1. Проверьте API ключ (для OpenAI)
2. Убедитесь, что Ollama запущен (для Ollama)
3. Используйте простой режим: `use_llm: false`
