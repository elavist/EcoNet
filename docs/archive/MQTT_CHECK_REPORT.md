## Конфигурация MQTT

### Брокер
- **Host:** localhost
- **Port:** 1883
- **TLS:** отключен
- **Аутентификация:** не используется

### Топики (9 топиков)

1. **detection:** `obelisk/detection`
   - Детекции объектов

2. **model_update:** `obelisk/model/update`
   - Обновления моделей

3. **robot_heartbeat:** `robots/{robot_id}/heartbeat`
   - Heartbeat от роботов (wildcard: `robots/+/heartbeat`)

4. **robot_status:** `robots/{robot_id}/status`
   - Статус роботов (wildcard: `robots/+/status`)

5. **robot_telemetry:** `robots/{robot_id}/telemetry`
   - Телеметрия роботов (wildcard: `robots/+/telemetry`)

6. **system_status:** `obelisk/system/status`
   - Статус системы

7. **task_completed:** `obelisk/tasks/completed`
   - Завершенные задачи

8. **task_failed:** `obelisk/tasks/failed`
   - Проваленные задачи

9. **tasks:** `obelisk/tasks`
   - Задачи для роботов

## Использование MQTT в коде

### Основные компоненты

1. **obelisk/services/mqtt_client.py**
   - Основной MQTT клиент
   - Поддержка асинхронных операций
   - Обработка подписок и публикаций

2. **obelisk/api/main.py**
   - Инициализация MQTT клиента при запуске
   - Интеграция с FastAPI lifespan

3. **obelisk/services/task_manager.py**
   - Подписка на топики задач
   - Обработка детекций
   - Управление задачами роботов

4. **edge/inference_service/detector.py**
   - Публикация детекций в MQTT
   - Использование отдельного MQTT клиента

5. **robots/collector/collector_robot.py**
   - Heartbeat через MQTT
   - Получение задач через MQTT

## Исправления

### ✅ Исправлена обработка асинхронных callback'ов
- Проблема: "no running event loop" при вызове async callbacks
- Решение: Улучшена обработка callbacks с проверкой активного event loop
- Результат: Callbacks работают корректно

### ✅ Улучшено логирование отключений
- Нормальные отключения (rc=0) логируются на уровне DEBUG
- Ошибки логируются реже (при первом отключении или каждые 10)
- Добавлена диагностика причин отключений

### ✅ Уникальный client_id
- Используется UUID для генерации уникального client_id
- Избежание конфликтов при множественных подключениях
