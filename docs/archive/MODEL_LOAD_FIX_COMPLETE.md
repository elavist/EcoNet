**PyTorch/YOLO теряет кавычки в пути при загрузке модели**

Это известная проблема Windows с путями, содержащими специальные символы (кавычки).

### Возможные решения:

1. **Переименовать папку** (рекомендуется) ⭐
   - Изменить имя папки с `Project '' EcoNet''` на `Project_EcoNet`
   - Это решит проблему навсегда

2. **Использовать относительный путь**
   - Если это возможно в вашем случае

3. **Создать symlink**
   - Создать ссылку на папку без кавычек

4. **Использовать короткое имя пути (8.3)**
   - Windows может создать короткое имя без кавычек
