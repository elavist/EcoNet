# 🚀 Запуск ЭкоНет

## Быстрый запуск

### Вариант 1: Команда (рекомендуется)
```bash
python scripts\run_econet.py
```

### Вариант 2: Двойной клик
Дважды кликните на файл `ЗАПУСТИТЬ_ЭКОНЕТ.bat`

### Вариант 3: Через GUI скрипт
```bash
python scripts\run_gui.py
```

## Что происходит при запуске

1. **Инициализация системы самоидентификации**
   - Сканирование кодовой базы
   - Анализ структуры проекта
   - Создание карты компонентов

2. **Запуск компонентов**
   - UnifiedEngine (центральный координатор)
   - ModelEngine (управление YOLO моделями)
   - VisionContext (визуальный анализ)
   - ActiveLearner (активное обучение)
   - TaskManager (координация задач)

3. **Открытие GUI**
   - Современный интерфейс 2025
   - Видеоплеер с полным управлением
   - Инструменты разметки
   - Выбор модели с метриками
   - Управление источниками видео

## Компоненты системы

### UnifiedEngine (Центральный координатор)
- **Файл**: `obelisk/core/unified_engine.py`
- **Назначение**: Координация всех компонентов системы
- **Функции**: Обработка кадров, управление роем, координация задач

### ModelEngine (Управление моделями)
- **Файл**: `obelisk/core/model_engine.py`
- **Назначение**: Управление YOLO моделями с поддержкой ансамбля
- **Оптимизации**: GPU ускорение, FP16, batch processing

### Material Design GUI (Интерфейс)
- **Файл**: `obelisk/ui/gui_material.py`
- **Назначение**: Современный графический интерфейс
- **Возможности**: Видеоплеер, инструменты разметки, выбор модели

## Интерфейс 2025

Современный дизайн включает:
- **Glassmorphism** - полупрозрачные элементы
- **Градиенты** - плавные переходы цветов
- **Скругленные углы** - современная геометрия
- **Современная типографика** - Segoe UI, правильные размеры
- **Яркие акцентные цвета** - Индиго, Циан, Янтарный
- **Плавные анимации** - эффекты наведения и нажатия

## Первое использование

После запуска вы можете:
- Импортировать видео для обработки
- Запустить детекцию в реальном времени
- Размечать объекты вручную
- Выбирать модель из версий обучения
- Просматривать метрики моделей
