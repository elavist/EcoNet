# ✅ Исправление приоритета загрузки моделей (PT vs ONNX)

## ❌ Проблема

```
ERROR:obelisk.core.model_engine:Ошибка детекции моделью primary: Error in execution: Got invalid dimensions for input: images for the following indices
 index: 2 Got: 640 Expected: 416
 index: 3 Got: 640 Expected: 416
 Please fix either the inputs/outputs or the model.
```

**Причина:**
- ONNX модель была экспортирована с фиксированным размером входа **416x416**
- Система пыталась загрузить ONNX модель (приоритет ONNX)
- При детекции использовался размер 640 из конфига
- ONNX модель не поддерживает изменение размера входа

## ✅ Решение

### 1. **Изменен приоритет загрузки моделей**

**Было:** Приоритет ONNX (быстрее)
```python
if onnx_path.exists():
    # Загружаем ONNX
elif model_path_obj.exists():
    # Загружаем PT
```

**Стало:** Приоритет PT (гибкость размера)
```python
# ПРИОРИТЕТ PT модели (поддерживает любые размеры)
if model_path_obj.exists() and model_path_obj.suffix == '.pt':
    # Загружаем PT
elif onnx_path.exists():
    # Загружаем ONNX (если PT нет)
```

### 2. **Определение размера входа в зависимости от типа модели**

В `_single_model_detect()`:
```python
model_is_onnx = self.model_is_onnx.get(model_name, False)

if model_is_onnx:
    # Для ONNX используем фиксированный размер 416
    input_size = 416
    logger.warning(f"⚠️ ONNX модель - используется размер: {input_size}")
else:
    # Для PT используем размер из конфига (640)
    input_size = config_input_size
    logger.debug(f"🚀 PT модель - используется размер: {input_size}")
```

## 📊 Изменения

### `obelisk/core/model_engine.py`:

1. **Приоритет PT модели при загрузке:**
   - Сначала проверяется наличие PT модели
   - Если PT модель есть - загружается она
   - Если PT модели нет - загружается ONNX

2. **Автоматическое определение размера:**
   - PT модель → использует размер из конфига (640)
   - ONNX модель → использует фиксированный размер (416)

## 🎯 Результат

- ✅ PT модель загружается с приоритетом (поддерживает размер 640)
- ✅ ONNX модель используется только если PT нет (с размером 416)
- ✅ Автоматическое определение размера в зависимости от типа модели
- ✅ Максимальное количество детекций через PT модель с размером 640

## ⚠️ Важно

- **PT модели** поддерживают любые размеры (640, 800, 1024 и т.д.)
- **ONNX модели** имеют фиксированный размер (обычно 416)
- Если нужен размер 640 - использовать PT модель
- Если есть и PT, и ONNX - будет загружена PT модель

**Проблема исправлена!** ✅
