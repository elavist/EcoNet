## ✅ Выполненные Улучшения

### 1. 🧮 Улучшенная Математика Ансамбля Моделей

#### IoU (Intersection over Union) Группировка
- **Было**: Простое округление координат для группировки детекций
- **Стало**: Точная группировка с использованием IoU для перекрывающихся детекций
- **Преимущества**:
  - Правильное объединение детекций от разных моделей
  - Учет реального перекрытия, а не только близости координат
  - Настраиваемый порог IoU (по умолчанию 0.5)

#### Динамические Веса Моделей
- **Формула**: `effective_weight = base_weight × reliability_factor`
- **reliability_factor**: `0.8 + (avg_confidence × 0.4)`
- **Преимущества**:
  - Автоматическая адаптация весов на основе производительности
  - Более надежные модели получают больший вес
  - Учитывается историческая средняя уверенность

#### Комбинированное Взвешивание
- **Формула**: `conf_weight = model_weight × detection_confidence`
- **Применение**: Используется при взвешенном усреднении координат и уверенности
- **Преимущества**:
  - Учитывается как качество модели, так и качество конкретной детекции
  - Высокоуверенные детекции имеют больший вес
  - Более точные результаты объединения

#### Улучшенные Методы Голосования
1. **Weighted Voting** - Взвешенное голосование с IoU группировкой
2. **Majority Voting** - Голосование большинством с IoU группировкой
3. **Average Voting** - Усреднение с IoU группировкой и голосованием по классам

**Файлы**: `obelisk/core/model_engine.py`

### 2. 🤖 Улучшенный Алгоритм Выбора Робота

#### Многокритериальная Оптимизация

##### Факторы Оценки:
1. **Расстояние** (вес: 0.5-0.6)
   - Логарифмическая нормализация: `1.0 / (1.0 + log(1.0 + distance / 10.0))`
   - Сглаживание больших расстояний
   - Приоритет близким роботам

2. **Уровень Батареи** (вес: 0.2-0.25)
   - Квадратичная функция: `(battery / 100.0) ** 1.5`
   - Приоритет высокому заряду
   - Штрафы:
     - <20%: ×0.1 (сильный штраф)
     - <50%: ×0.7 (умеренный штраф)

3. **Текущая Загрузка** (вес: 0.05-0.1)
   - Экспоненциальное снижение: `exp(-current_tasks / 2.0)`
   - Предпочтение менее загруженным роботам

4. **Эффективность Робота** (вес: 0.1-0.15)
   - Историческая производительность
   - Ограничение сверху: `min(efficiency, 1.5) / 1.5`

5. **Время с Последнего Обслуживания** (вес: 0.0-0.05)
   - Экспоненциальное снижение: `exp(-last_maintenance / 168.0)`
   - Предпочтение недавно обслуживаемым роботам

#### Адаптивные Веса для Приоритетов
- **Срочные задачи**: Увеличенный вес расстоянию (0.6) и эффективности (0.15)
- **Обычные задачи**: Сбалансированные веса

**Файлы**: `obelisk/services/task_manager.py`

## 🔧 Технические Детали

### Математические Формулы

#### IoU (Intersection over Union)
```
IoU = Intersection(bbox1, bbox2) / Union(bbox1, bbox2)
```

#### Динамический Вес Модели
```
effective_weight = base_weight × (0.8 + avg_confidence × 0.4)
```

#### Комбинированный Вес Детекции
```
conf_weight = model_weight × detection_confidence
weighted_value = Σ(value × conf_weight) / Σ(conf_weight)
```

#### Оценка Робота
```
score = w1×distance_score + w2×battery_score + w3×load_score + 
        w4×efficiency_score + w5×maintenance_score
```
