## 🔄 Порядок Обработки

### Предобработка видео:

```
1. ДЕТЕКЦИЯ (максимальная):
   ├─ confidence: 0.2 (низкий порог)
   ├─ input_size: 640 (большой размер)
   ├─ max_detections: 300 (максимум)
   └─ Результат: ВСЕ возможные объекты детектируются

2. ТРЕКИНГ (после детекции):
   ├─ IoU threshold: 0.86 (86% совпадение)
   ├─ Применяется К ВСЕМ детекциям
   ├─ Добавляет track_id к детекциям
   └─ НЕ удаляет детекции (только группирует и отслеживает)

3. СОХРАНЕНИЕ:
   ├─ Все детекции с track_id сохраняются
   └─ Используются при воспроизведении
```

## ✅ Результат

**Система настроена на максимальное количество детекций!**

1. ✅ Низкий confidence threshold (0.2) - детектируется больше объектов
2. ✅ Увеличенный input_size (640) - лучшая детализация
3. ✅ Больше max_detections (300) - больше объектов на кадр
4. ✅ Мягкая фильтрация (iou 0.4) - меньше потеря детекций
5. ✅ Трекинг применяется ПОСЛЕ детекции - не уменьшает количество

## 📝 Примечания

- Трекинг **не уменьшает** количество детекций, только добавляет track_id
- Все детекции сохраняются с track_id
- При воспроизведении используются сохраненные детекции
- Трекинг работает только при предобработке видео
