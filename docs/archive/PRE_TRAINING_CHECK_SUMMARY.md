## 📝 Запуск обучения

### Вариант 1: Обучение с нуля (рекомендуется)

```bash
python scripts/train_model.py
```

**Что делает:**
- Загружает предобученную модель (yolov8n.pt)
- Использует GPU если доступен (cuda:0)
- Оптимальный размер батча (32 для GPU, 16 для CPU)
- Automatic Mixed Precision (AMP) для ускорения на GPU
- 100 эпох обучения
- Сохраняет лучшую модель автоматически

### Вариант 2: Быстрый тест (5 эпох)

Для быстрого теста измените в `scripts/train_model.py`:
```python

```

- **Эпохи**: 100
- **Батч**: 32 (GPU) / 16 (CPU)
- **Размер изображения**: 640x640
- **Устройство**: GPU (cuda:0) если доступен, иначе CPU
- **AMP**: Включен для GPU (ускорение на 20-30%)
