# 🔍 Диагностика Детекции

## 📋 Добавлено Подробное Логирование

Добавлено подробное логирование на всех этапах обработки детекции для диагностики проблемы:

### 1. GUI (gui_material.py)

**`_on_video_frame`:**
- `🔍 _on_video_frame: detection_filter_enabled=...` - проверка состояния фильтра
- `🔍 Проверка готовности: is_ready=...` - проверка готовности ModelEngine
- `🚀 Запуск обработки кадра` - запуск обработки
- `⚠️ ModelEngine не готов` - предупреждение если модель не готова
- `❌ Event loop не готов` - ошибка если event loop не готов

**`_process_frame_async`:**
- `🎬 _process_frame_async вызван` - начало обработки
- `❌ UnifiedEngine не инициализирован` - ошибка если UnifiedEngine не готов
- `❌ ModelEngine не доступен` - ошибка если ModelEngine не доступен
- `❌ ModelEngine не имеет загруженных моделей` - ошибка если нет моделей
- `📦 Доступные модели: ...` - список доступных моделей
- `🚀 Вызов unified_engine.process_frame` - вызов обработки
- `📊 Результат обработки: detections=...` - результат обработки
- `✅ Получено X детекций!` - успешное получение детекций
- `⚠️⚠️⚠️ Детекций НЕ получено` - предупреждение если детекций нет

### 2. UnifiedEngine (unified_engine.py)

**`_detect_async`:**
- `🔍 _detect_async вызван` - начало детекции
- `🔍 Начало детекции через YOLO-нейрон` - детекция через нейрон
- `✅ YOLO-нейрон вернул X детекций` - результат от нейрона
- `❌ ModelEngine не доступен` - ошибка если ModelEngine не доступен
- `❌ ModelEngine не имеет загруженных моделей` - ошибка если нет моделей
- `📦 ModelEngine имеет X модель(ей)` - количество моделей
- `🚀 Вызов model_engine.detect_frame` - вызов детекции
- `✅✅✅ ModelEngine вернул X детекций!` - успешная детекция
- `⚠️⚠️⚠️ ModelEngine не нашел детекций` - предупреждение если детекций нет

### 3. ModelEngine (model_engine.py)

**`detect_frame`:**
- `🔍 ModelEngine.detect_frame вызван` - начало детекции
- `❌ Нет загруженных моделей` - ошибка если нет моделей
- `📦 Доступные модели: ...` - список моделей
- `🔀 Использование ансамбля моделей` - использование ансамбля
- `🎯 Использование одной модели: ...` - использование одной модели

**`_single_model_detect`:**
- `🔍 _single_model_detect: model_name=...` - начало детекции одной моделью
- `🚀 Вызов YOLO модели` - вызов YOLO
- `✅ YOLO модель вернула результаты` - результаты от YOLO
- `📦 Результат содержит X боксов` - количество боксов
- `✅✅✅ _single_model_detect вернул X детекций!` - успешная детекция
- `📦 Первая детекция: bbox=..., conf=...` - первая детекция

## 🔍 Как Использовать

1. Запустите программу
2. Загрузите видео
3. Включите детекцию (галочка должна быть включена)
4. Смотрите логи в консоли

**Ожидаемый поток логов:**
```
🔍 _on_video_frame: detection_filter_enabled=True, unified_engine=есть, loop=есть
🔍 Проверка готовности: is_ready=True, model_engine=есть

🎬 _process_frame_async вызван для кадра (640, 480, 3)
📦 Доступные модели: ['primary']
🔍 Обработка кадра размером: (640, 480, 3)
🚀 Вызов unified_engine.process_frame для кадра (640, 480, 3)
🔍 _detect_async вызван: frame_id=..., frame.shape=(640, 480, 3)
📦 ModelEngine имеет 1 модель(ей): ['primary']
🔍 ModelEngine.detect_frame вызван: models=1
🎯 Использование одной модели: primary
🔍 _single_model_detect: model_name=primary, frame.shape=(640, 480, 3)
🚀 Вызов YOLO модели primary с параметрами: {...}
✅ YOLO модель primary вернула результаты: 1 результатов
📦 Результат содержит X боксов

```

## ⚠️ Возможные Проблемы

1. **"ModelEngine не готов"** - модель не инициализирована
2. **"Нет загруженных моделей"** - модели не загружены
3. **"Детекций НЕ получено"** - модель не находит объекты (проверьте модель и кадр)
4. **"Event loop не готов"** - проблема с asyncio

## ✅ Следующие Шаги

После запуска с логированием проверьте:
1. Вызывается ли `_process_frame_async`?
2. Вызывается ли `model_engine.detect_frame`?
3. Вызывается ли YOLO модель?
4. Возвращаются ли детекции?

Это поможет найти точное место проблемы! 🔍
