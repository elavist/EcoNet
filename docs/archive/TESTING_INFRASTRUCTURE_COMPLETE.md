## Как использовать

### Установка

```bash
pip install -r requirements.txt
```

### Запуск всех тестов

```bash
# Из корня проекта
pytest tests/

# С подробным выводом
pytest tests/ -v

# С покрытием кода
```

## Обсуждение идеи дообучения на одном файле

### ✅ ИДЕЯ ХОРОШАЯ!

**Стратегия**: Дообучить модель на одном файле с 100 эпохами, чтобы модель "приняла" эти данные как "родные".

### Преимущества:

1. **Адаптация под конкретные условия** - модель адаптируется под специфические условия (освещение, угол, фон)
2. **Высокая уверенность** - после дообучения модель детектирует похожие объекты с высокой уверенностью
3. **Быстрая адаптация** - не нужно собирать большой датасет

### Риски:

1. **Переобучение (Overfitting)** - основная проблема
2. **Потеря общей точности** - модель может начать хуже работать на других данных
3. **Долгое обучение** - 100 эпох может занять много времени

### ⚠️ КРИТИЧЕСКИ ВАЖНО:

1. **ОБЯЗАТЕЛЬНО использовать Data Augmentation**:
   - Random flip, crop, rotation
   - Color jitter (яркость, контраст, насыщенность)
   - Gaussian blur
   - И т.д.
   
   **Это превратит один файл в множество вариаций!**

2. **ОБЯЗАТЕЛЬНО использовать Early Stopping**:
   - Отслеживать validation loss
   - Останавливать, если validation loss начинает расти
   - Сохранять лучшую модель

3. **ОБЯЗАТЕЛЬНО валидировать**:
   - Использовать отдельный validation set
   - Проверять метрики на разных данных
   - Убедиться, что модель не потеряла обобщающую способность

4. **ОБЯЗАТЕЛЬНО мониторить метрики**:
   - Training loss (должна уменьшаться)
   - Validation loss (НЕ должна расти - признак переобучения)
   - Precision/Recall на validation set
