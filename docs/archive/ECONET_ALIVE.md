# 🤖 ЭкоНет - Полная реализация (Обновлено 2025)

## ✅ Что было реализовано

ЭкоНет теперь **полноценная автономная система роя** с возможностью детекции, координации роботов и управления через современный интерфейс!

**⚠️ Примечание**: Chat/LLM функционал был удален на данном этапе для оптимизации производительности.

---

## 🎯 Основные компоненты

### 1. **UnifiedEngine** (`obelisk/core/unified_engine.py`)
- ✅ Координация всех компонентов системы
- ✅ Обработка кадров (детекция + визуальный анализ)
- ✅ Управление роем роботов
- ✅ Асинхронная архитектура (asyncio)
- ✅ Кэширование и оптимизация

### 2. **ModelEngine** (`obelisk/core/model_engine.py`)
- ✅ Управление YOLO моделями с ансамблем
- ✅ Три метода объединения детекций
- ✅ Оптимизация производительности (ONNX, GPU, FP16)
- ✅ Приоритет PT моделей над ONNX

### 3. **MediaManager** (`obelisk/services/media_manager.py`)
- ✅ Управление медиа файлами (видео, фото)
- ✅ Предобработка видео (автоматическая обработка YOLO)
- ✅ Хранение детекций (pickle файлы)
- ✅ Управление статусом обработки

### 4. **Material Design GUI** (`obelisk/ui/gui_material.py`)
- ✅ Современный интерфейс для управления
- ✅ Видеоплеер с полным управлением
- ✅ Инструменты разметки
- ✅ Выбор модели с метриками
- ✅ Очистка кэша
- ✅ Статус системы в реальном времени

### 5. **AnnotationTool** (`obelisk/services/annotation_tool.py`)
- ✅ Инструмент ручной разметки
- ✅ Сохранение в формате YOLO
- ✅ Автоматическое добавление в датасет
- ✅ Быстрые действия (кнопки)
- ✅ Индикатор подключения
- ✅ Адаптивный дизайн

## 🚀 Как использовать

### Вариант 1: CLI (рекомендуется для начала)

```powershell
# Запуск интерактивного диалога
python scripts\chat_with_econet.py

# С автоматическим запуском детекции
python scripts\chat_with_econet.py --source 0
python scripts\chat_with_econet.py --source http://192.168.1.XXX:8080/video
```

**Команды в диалоге:**
- `start <источник>` - Запустить детекцию
- `stop` - Остановить детекцию
- `status` - Статус системы
- `clear` - Очистить историю
- `help` - Помощь
- `quit` / `exit` - Выход

**Примеры вопросов:**
- "Что видишь?" - Что видит система
- "Сколько окурков?" - Количество детекций
- "Где окурки?" - Расположение объектов
- "Это окурок" - Обучение (положительная обратная связь)
- "Это не окурок" - Обучение (отрицательная обратная связь)

### Вариант 2: Веб-интерфейс

```powershell
# Запуск сервера
python obelisk\api\main.py

# Откройте в браузере
http://localhost:8000/chat
```

### Вариант 3: REST API

```powershell
# Запуск сервера
python obelisk\api\main.py

# Отправка сообщения (curl)
curl -X POST "http://localhost:8000/api/v1/chat/message" \
  -H "Content-Type: application/json" \
  -d '{"message": "Что видишь?"}'
```

## 🧠 Как это работает

### 1. Визуальное понимание

Система анализирует каждый кадр:
- **Детекции**: количество, уверенность, расположение
- **Качество изображения**: яркость, контраст, резкость
- **Сцена**: тип поверхности, сложность

### 2. Понимание намерений

Система классифицирует сообщения:
- **Вопросы о видении** → Ответ на основе визуального контекста
- **Команды** → Выполнение действий
- **Обучение** → Сохранение обратной связи
- **Статус** → Информация о системе

### 3. Генерация ответов

- **Простой режим** (по умолчанию): правила и шаблоны
- **LLM режим** (опционально): умные ответы через OpenAI/Ollama

### 4. Интерактивное обучение

Когда вы даёте обратную связь:
- Система запоминает примеры
- Интегрируется с активным обучением
- Использует для улучшения модели

## 📋 Конфигурация

### `config/config.yaml`

```yaml
chat:
  enabled: true  # Включить интерактивный диалог
  use_llm: false  # Использовать LLM (OpenAI/Ollama)
  llm_provider: "openai"  # openai, ollama, local
  llm_model: "gpt-4o-mini"
  llm_api_key: null  # Установить через OPENAI_API_KEY
  max_history: 50  # Максимум сообщений в истории
```

### Использование LLM (опционально)

**OpenAI:**
```yaml
chat:
  use_llm: true
  llm_provider: "openai"
  llm_model: "gpt-4o-mini"
  llm_api_key: "sk-..."  # Или через переменную окружения
```

**Ollama (локально):**
```yaml
chat:
  use_llm: true
  llm_provider: "ollama"
  llm_model: "llama2"
```

## 🐛 Решение проблем

### "Сервис диалога не инициализирован"

Убедитесь, что в `config/config.yaml`:
```yaml
chat:
  enabled: true
```

### "Не вижу окурков"

1. Запустите детекцию: `start <источник>`
2. Убедитесь, что камера работает
3. Проверьте порог уверенности в конфигурации

### LLM не работает

1. Проверьте API ключ (для OpenAI)
2. Убедитесь, что Ollama запущен (для Ollama)
3. Используйте простой режим: `use_llm: false`
