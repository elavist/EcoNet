## 📊 Логика Работы

### Обработка видео:

```
1. Импорт видео → копирование в data/media/videos/
2. Автоматическая обработка (после проверки модели):
   - YOLO детекция каждого кадра
   - Трекинг объектов (IoU > 0.86)
   - Сохранение детекций с track_id
3. Обновление статистики:
   - "Обработано": количество обработанных видео
   - "Кадров": количество кадров с детекциями
   - "Детекций": общее количество детекций
4. Сохранение в data/media/detections/{file_id}_detections.pkl
```

### Воспроизведение:

```
1. Выбор видео из списка → load_media_file(file_id)
2. Проверка processed: true → если нет - предупреждение
3. Загрузка детекций → load_detections(file_id)
4. Загрузка видео → video_display.load_video(file_path)
5. Сохранение:
   - current_media_file = file_meta
   - current_saved_detections = saved_detections
   - current_frame_number = 0
6. Воспроизведение:
   - Используется video_display.current_frame_number
   - Загружаются детекции для текущего кадра
   - Отображение с track_id
```

### Трекинг объектов (IoU > 0.86):

```
1. При обработке кадра:
   - Вычисление IoU между существующими треками и новыми детекциями
   - Сопоставление по максимальному IoU (если > 0.86)
   - Обновление существующих треков
   - Создание новых треков для несопоставленных детекций
2. Каждая детекция получает track_id
3. Сохранение детекций с track_id для последующего использования
```
